MarkovInference

Conditional increment moments and their functionals: kramers_moyal $\equiv D^{(n)}$, drift $\equiv D^{(1)}$, diffusion $\equiv D^{(2)}$, the pawula_quotient, and the markov_test (§4.4).

GBGStreamingStatistics.MarkovInference.diffusion — Method
diffusion(summary::Histogram2D, x; h, τ = summary.lag)   # ≡ D⁽²⁾(x)

Estimand. the second Kramers–Moyal coefficient $D^{(2)}(x) = \tfrac{1}{2}\lim_{\tau \to 0} M_2(x, \tau)/\tau$ — the $n = 2$ kramers_moyal coefficient (the $\tfrac{1}{2} = 1/2!$ is the Kramers–Moyal normalization). For the SDE $\mathrm{d}X = D^{(1)}\,\mathrm{d}t + \sqrt{2 D^{(2)}}\,\mathrm{d}W$ a consumer reads $\sqrt{2 D^{(2)}}$ as the noise amplitude (so $D^{(2)} = \sigma^2/2$ for additive $\sigma\,\mathrm{d}W$); the package asserts no such model.

Estimator. $\widehat{D}^{(2)}(x) = M_2(x, \tau)/(2\tau)$ with $M_2$ the conditional increment_moment. h is the supplied bandwidth; a vector x returns a vector.

GBGStreamingStatistics.MarkovInference.drift — Method
drift(summary::Histogram2D, x; h, τ = summary.lag)   # ≡ D⁽¹⁾(x)

Estimand. the first Kramers–Moyal coefficient $D^{(1)}(x) = \lim_{\tau \to 0} M_1(x, \tau)/\tau$ — the $n = 1$ kramers_moyal coefficient. For an Itô SDE $\mathrm{d}X = D^{(1)}(X)\,\mathrm{d}t + \sqrt{2 D^{(2)}(X)}\,\mathrm{d}W$ a consumer reads it as the drift; the package asserts no such model.

Estimator. $\widehat{D}^{(1)}(x) = \bigl(\hat m_h(x) - x\bigr)/\tau$ — the local-linear increment mean over the lag time $\tau$. h is the supplied bandwidth; a vector x returns a vector.

GBGStreamingStatistics.MarkovInference.increment_moment — Method
increment_moment(summary::Histogram2D, x, n; h)   # ≡ M_n(x, τ)

Estimand. the conditional increment moment $M_n(x, \tau) = \mathbb{E}\!\left[(X_{t+\tau} - X_t)^n \mid X_t = x\right]$ — the $n$-th moment of the lag-$\tau$ increment $\Delta X = X_{t+\tau} - X_t$ conditioned on the present value $x$. A pure conditional expectation; no model is assumed.

Estimator. writing $Y = X_{t+\tau}$ for the response stored in the joint Histogram2D at lag $\tau$ and conditioning on $X_t = x$ (so $\Delta X = Y - x$), the first two moments are conditional moments of $Y$:

\[M_1(x, \tau) = \hat m_h(x) - x, \qquad M_2(x, \tau) = \widehat{\mathbb{E}}[Y^2 \mid x] - 2x\,\hat m_h(x) + x^2 ,\]

with $\hat m_h(x) = \widehat{\mathbb{E}}[Y \mid x]$ the local-linear conditional_mean and $\widehat{\mathbb{E}}[Y^2 \mid x]$ the same fit applied to the $Y^2$ response — both exact from the per-cell power-sums. Hence $n \in \{1, 2\}$ (drift and diffusion); $n \ge 3$ (the Pawula $M_4$, $M_6$) needs the summary raised to order-$n$ per-cell $Y$ power-sums — a recorded coverage gap, so it throws rather than silently approximate. h is the supplied smoothing bandwidth; a vector x returns a vector.

GBGStreamingStatistics.MarkovInference.kramers_moyal — Method
kramers_moyal(summary::Histogram2D, x, n; h, τ = summary.lag)   # ≡ D⁽ⁿ⁾(x)

Estimand. the $n$-th Kramers–Moyal coefficient $D^{(n)}(x) = \dfrac{1}{n!}\,\lim_{\tau \to 0} \dfrac{M_n(x, \tau)}{\tau}$, with $M_n$ the conditional increment_moment.

Estimator. the finite-$\tau$ ratio $\widehat{D}^{(n)}(x) = \widehat{M}_n(x, \tau)\,/\,(n!\,\tau)$ at the summary's lag $\tau$. The keyword τ is the physical lag time; it defaults to the integer lag label of the summary (exact when the sampling interval is the time unit). For small $\tau$ this approximates $D^{(n)}$ to $O(\tau)$; the all-orders finite-time (Bell-polynomial) correction that inverts the $\tau$-expansion rather than extrapolating (Rydin Gorjão et al. 2021) is forthcoming. Supports $n \in \{1, 2\}$ — see drift and diffusion.

Model-neutral. $D^{(n)}$ is defined and estimated without assuming the data is a diffusion. That $D^{(1)}$ "is" drift, that the $D^{(n)}$ are coefficients of a Fokker–Planck operator — these are the consumer's interpretation; the package supplies the estimator and the tests of the hypothesis (see pawula_quotient, markov_test).

Reference: A. Rydin Gorjão et al. (2021), Kramers–Moyal coefficients with finite-time corrections.

GBGStreamingStatistics.MarkovInference.markov_test — Function
markov_test(summaries...; ...)

A $\chi^2$ Markov / Chapman–Kolmogorov test: a hypothesis test of whether the data is Markovian, comparing the two-step transition density against the Chapman–Kolmogorov composition of one-step densities (see transition_density). Intrinsically finite-sample — a test, not an estimand.

GBGStreamingStatistics.MarkovInference.pawula_quotient — Function
pawula_quotient(summary, x; ...)   # ≡ Q(x)

Estimand. the Pawula / $Q$ diagnostic $Q(x) = M_6(x, \tau) / \bigl(5\, M_4(x, \tau)^2\bigr)$ (with $M_n$ the conditional increment_moment) — a test of whether the higher Kramers–Moyal coefficients vanish (Pawula's theorem), not a premise. A small $Q$ supports a diffusion reading; a large one refutes it.

Forthcoming — needs the order raise

Declared; not yet implemented. $M_4$ and $M_6$ require the joint summary raised to per-cell $Y$ power-sums of order 4–6, beyond the current order-2 Histogram2D — a recorded coverage gap (docs/ARCHITECTURE.md §4.4).
