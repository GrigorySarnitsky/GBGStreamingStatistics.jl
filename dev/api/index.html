API overview

The complete public API, grouped by module on the pages that follow. Every estimator is documented estimand first — the population quantity, in standard probability notation, before the estimator that approximates it from the accumulated summary.

The lower half (Accumulators, Histograms) holds the summaries and the accumulation primitives; the upper half (DensityEstimation through Bandwidth) holds the estimands.
