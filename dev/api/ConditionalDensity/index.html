ConditionalDensity

The conditional density conditional_density $\equiv f_{Y\mid X}$ and the two-time transition density transition_density $\equiv p_\tau(y\mid x)$.

GBGStreamingStatistics.ConditionalDensity.conditional_density — Function
conditional_density(summary::Histogram2D, x, y;
                    hx, hy, kernelx = gaussian_kernel, kernely = gaussian_kernel,
                    normalize = false)   # ≡ f_{Y|X}

Estimand. the conditional density $f_{Y\mid X}(y \mid x) = f_{X,Y}(x, y) / f_X(x)$.

Estimator (double-kernel; Rosenblatt 1969; Hyndman, Bashtannyk & Grunwald 1996). From the joint Histogram2D summary, with a conditioning kernel $K_1 =$ kernelx (bandwidth $h_1 =$ hx, in $x$) and a response kernel $K_2 =$ kernely (bandwidth $h_2 =$ hy, in $y$); both $\int K = 1$, default gaussian_kernel,

\[\hat f(y \mid x) = \frac{\sum_i K_{h_1}(X_i - x)\, K_{h_2}(Y_i - y)}{\sum_i K_{h_1}(X_i - x)} ,\]

evaluated from the bin counts $n_{jk}$ at cell centers $(c^x_j, c^y_k)$ (the binned form, with $N_j = \sum_k n_{jk}$ the per-column count):

\[\hat f(y \mid x) = \frac{\sum_{j,k} n_{jk}\, K_{h_1}(c^x_j - x)\, K_{h_2}(c^y_k - y)} {\sum_{j} N_j\, K_{h_1}(c^x_j - x)} .\]

The $x$-kernel weighting cancels in the ratio (it appears in both the profile and its total), so the choice of kernelx only weights the local conditioning window. For a symmetric response kernely the surviving $1/h_2$ makes $\int \hat f(y \mid x)\,\mathrm{d}y = 1$ exactly (since $\int K = 1$). For a bounded / positive response — a droplet radius as $Y$, say — pass an asymmetric kernely (gamma_kernel for $[0,\infty)$, beta_kernel for $[0,1]$), the same boundary-bias fix the marginal density uses: it is a density in the data argument $K_2(c^y_k;\, y, h_2)$ (no mass leaks past the edge) but only $\approx$ normalized in $y$, so set normalize = true to enforce $\int \hat f\,\mathrm{d}y = 1$ exactly. (A bounded conditioning variable needs no asymmetric kernelx: the $x$-kernel cancels in the $f_{X,Y}/f_X$ ratio, so its boundary leakage does not bias $f_{Y\mid X}$.) The conditional MISE rate is slower than a marginal density ($O(n^{-2/3})$). A vector y returns the density curve over those points at the fixed conditioning value x; where no data is local to x the estimate is NaN.

Arguments:

  • summary — the joint Histogram2D of $(X, Y)$.
  • x — the conditioning value (a scalar).
  • y — the response point(s) at which the density is evaluated (a scalar, or a vector for the curve).
  • hx, hy — the conditioning ($x$) and response ($y$) bandwidths (both $> 0$), supplied.
  • kernelx — the conditioning-direction ($x$) kernel (any $\int K = 1$ callable; default gaussian_kernel). Its normalization cancels in the $f_{X,Y}/f_X$ ratio, so a symmetric kernel is almost always the right choice.
  • kernely — the response-direction ($y$) kernel (default gaussian_kernel). A symmetric kernel gives $\int\hat f\,\mathrm dy = 1$ exactly; an asymmetric AsymmetricKernel (gamma_kernel / beta_kernel), for a bounded / positive response, is boundary-bias-free but needs normalize = true for an exact integral.
  • normalize — when true, divide by $\int\hat f(y\mid x)\,\mathrm dy$ over the response range so the curve integrates to 1 exactly: the finishing step for an asymmetric kernely, a no-op for a symmetric one.
julia> g = Histogram2D(-1.0, 1.0, 2, -1.0, 1.0, 2);

julia> observe_pairs!(g, [0.4], [0.4]);   # one pair → cell with centers (0.5, 0.5)

julia> round(conditional_density(g, 0.5, 0.5; hx = 0.5, hy = 0.2); digits = 4)
1.9947

References:

  • M. Rosenblatt (1969), Conditional probability density and regression estimators, in Multivariate Analysis II.
  • R. J. Hyndman, D. M. Bashtannyk & G. K. Grunwald (1996), Estimating and visualizing conditional densities, J. Comput. Graph. Statist. 5(4).

GBGStreamingStatistics.ConditionalDensity.transition_density — Function
transition_density(summary::Histogram2D, x, y;
                   hx, hy, kernelx = gaussian_kernel, kernely = gaussian_kernel,
                   normalize = false)   # ≡ p_τ(y|x)

Estimand. the two-time transition density $p_\tau(y \mid x) = f_{X_{t+\tau} \mid X_t}(y \mid x)$ — the conditional density of the state a lag $\tau$ later, given the present state (nonstationary: $p_{t,\tau}$). For the Ornstein–Uhlenbeck process this is Gaussian in closed form.

Estimator. the conditional_density double-kernel estimator applied to the per-lag joint histogram of pairs $\bigl(X_t,\, X_{t+\tau}\bigr)$ (binned by observe_pairs! at the summary's lag $\tau$); the computation is identical — the name marks the two-time reading. The bandwidths hx (conditioning, in $x$), hy (response, in $y$), the kernels kernelx / kernely, and normalize are as for conditional_density. A vector y returns the transition-density curve at the fixed present state x.
