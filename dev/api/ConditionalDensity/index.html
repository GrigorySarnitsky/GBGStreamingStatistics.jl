ConditionalDensity

The conditional density conditional_density ($f_{Y\mid X}$) and the two-time transition density transition_density ($p_\tau(y\mid x)$), by the double-kernel estimator over a separate conditioning kernelx and response kernely (the asymmetric bounded-response kernels among them; see the Kernels page) — each with its pointwise standard error and the paired estimate-plus-error reader.

GBGStreamingStatistics.ConditionalDensity.conditional_density — Function
conditional_density(summary::Histogram2D, x, y;
                    hx, hy, kernelx = gaussian_kernel, kernely = gaussian_kernel,
                    normalize = false)   # ≡ f_{Y|X}

Estimand. The conditional density $f_{Y\mid X}(y \mid x) = f_{X,Y}(x, y) / f_X(x)$.

Estimator (double-kernel; Rosenblatt 1969; Hyndman, Bashtannyk & Grunwald 1996). From the joint Histogram2D summary, with a conditioning kernel $K_1$ (kernelx, of bandwidth $h_1$ given by hx, in $x$) and a response kernel $K_2$ (kernely, of bandwidth $h_2$ given by hy, in $y$); both $\int K = 1$, default gaussian_kernel,

\[\hat f(y \mid x) = \frac{\sum_i K_{h_1}(X_i - x) K_{h_2}(Y_i - y)}{\sum_i K_{h_1}(X_i - x)} ,\]

evaluated from the bin counts $n_{jk}$ at cell centers $(c^x_j, c^y_k)$ (the binned form, with $N_j = \sum_k n_{jk}$ the per-column count):

\[\hat f(y \mid x) = \frac{\sum_{j,k} n_{jk} K_{h_1}(c^x_j - x) K_{h_2}(c^y_k - y)} {\sum_{j} N_j K_{h_1}(c^x_j - x)} .\]

The $x$-kernel weighting cancels in the $f_{X,Y}/f_X$ ratio (it appears in both the profile and its total), so the choice of kernelx only weights the local conditioning window — a bounded conditioning variable thus needs no asymmetric kernelx. For a symmetric response kernely the surviving $1/h_2$ makes $\int \hat f(y \mid x)\,\mathrm{d}y = 1$ exactly (since $\int K = 1$). For a bounded / positive response — a droplet radius as $Y$, say — pass an asymmetric kernely (gamma_kernel for $[0,\infty)$, beta_kernel for $[0,1]$), the same boundary-bias fix the marginal density uses: it is a density in the data argument $K_2(c^y_k; y, h_2)$ (no mass leaks past the edge) but only $\approx$ normalized in $y$, so set normalize = true to enforce $\int \hat f\,\mathrm{d}y = 1$ exactly. The conditional MISE rate is slower than a marginal density ($O(n^{-2/3})$). A vector y returns the density curve over those points at the fixed conditioning value x; where no data is local to x the estimate is NaN.

Arguments

  • summary — the joint Histogram2D of $(X, Y)$.
  • x — the conditioning value (a scalar).
  • y — the response point(s) at which the density is evaluated (a scalar, or a vector for the curve).
  • hx, hy — the conditioning ($x$) and response ($y$) bandwidths (both $> 0$), supplied.
  • kernelx — the conditioning-direction ($x$) kernel (any $\int K = 1$ callable; default gaussian_kernel); as noted above it cancels in the ratio, so a symmetric kernel is almost always the right choice.
  • kernely — the response-direction ($y$) kernel (default gaussian_kernel). A symmetric kernel gives $\int\hat f\,\mathrm dy = 1$ exactly; an asymmetric gamma_kernel / beta_kernel, for a bounded / positive response, is boundary-bias-free but needs normalize = true for an exact integral — or supply your own AsymmetricKernel.
  • normalize — when true, divide by $\int\hat f(y\mid x)\,\mathrm dy$ over the response range so the curve integrates to 1 exactly: the finishing step for an asymmetric kernely, a no-op for a symmetric one.
julia> g = Histogram2D(-1.0, 1.0, 2, -1.0, 1.0, 2);

julia> observe_pairs!(g, [0.4], [0.4]);   # one pair → cell with centers (0.5, 0.5)

julia> round(conditional_density(g, 0.5, 0.5; hx = 0.5, hy = 0.2); digits = 4)
1.9947

References

  • M. Rosenblatt (1969), Conditional probability density and regression estimators (no DOI), in Multivariate Analysis II, Academic Press.
  • R. J. Hyndman, D. M. Bashtannyk & G. K. Grunwald (1996), Estimating and visualizing conditional densities, J. Comput. Graph. Statist. 5(4).

GBGStreamingStatistics.ConditionalDensity.conditional_density_standard_error — Function
conditional_density_standard_error(summary::Histogram2D, x, y;
                                   hx, hy, kernelx = gaussian_kernel,
                                   kernely = gaussian_kernel)   # ≡ SE[f̂(y∣x)]

Estimand. The pointwise standard error of the conditional-density estimator conditional_density, $\mathrm{SE}(y\mid x) = \sqrt{\operatorname{Var}\hat f(y\mid x)}$ with the double-kernel asymptotic variance

\[\operatorname{Var}\hat f(y\mid x) \approx \frac{R(K_1) R(K_2) f_{Y\mid X}(y\mid x)}{n h_1 h_2 f_X(x)} - \frac{f_{Y\mid X}(y\mid x)^2}{n}, \qquad R(K) = \int K^2 .\]

Here $f_X$ is the marginal density of the conditioning variable $X$, and the $-f^2/n$ term is the double-kernel analog of the marginal Wand–Jones correction.

Estimator. The two-term $\sqrt{R(K_1)R(K_2) \hat f(y\mid x)/(h_1 h_2 D) - \hat f(y\mid x)^2/n}$ from the recovered conditional density $\hat f(y\mid x)$, the bandwidths $h_1$ and $h_2$ (hx and hy), the kernel roughnesses $R(K_1)$, $R(K_2)$ (by quadrature), and the $x$-window denominator $D = \sum_j N_j K_{h_1}(c^x_j - x) = n \hat f_X(x)$ — the very sum conditional_density forms to normalize its profile, so $n \hat f_X(x)$ costs nothing extra. It is the two-dimensional analog of the marginal density_standard_error, with the $x$-window effective sample size $n h_1 \hat f_X(x)$ in place of $n$; the $z$-band $\hat f(y\mid x) \pm z \mathrm{SE}$ covers $f_{Y\mid X}$ where the $O(h^2)$ smoothing bias is small. Symmetric kernels only (the asymmetric-kernely variance is a recorded gap). NaN where no data is local to $x$.

Arguments

The arguments are as for conditional_density, without normalize (the band is for the un-normalized estimate):

  • summary — the joint Histogram2D of $(X, Y)$.
  • x — the conditioning value (a scalar).
  • y — the response point(s) at which the standard error is evaluated (a scalar, or a vector).
  • hx, hy — the conditioning ($x$) and response ($y$) bandwidths (both $> 0$).
  • kernelx, kernely — the conditioning and response kernels (default gaussian_kernel); symmetric kernels only.

Reference: R. J. Hyndman, D. M. Bashtannyk & G. K. Grunwald (1996), Estimating and visualizing conditional densities, J. Comput. Graph. Statist. 5(4).

conditional_density_with_standard_error(summary::Histogram2D, x, y;

The estimate and its standard error from one $x$-profile reduction — the NamedTuple $(\texttt{value}, \texttt{standard\_error})$, with value the conditional_density $\hat f(y\mid x)$ and standard_error its conditional_density_standard_error. They share the one profile, so they describe the same estimator by construction. For a vector y, returns a NamedTuple of vectors.

  • hx, hy — the conditioning ($x$) and response ($y$) bandwidths (both $> 0$).
  • kernelx, kernely — the conditioning and response kernels (default gaussian_kernel); symmetric kernels only.

GBGStreamingStatistics.ConditionalDensity.transition_density — Function
transition_density(summary::Histogram2D, x, y;
                   hx, hy, kernelx = gaussian_kernel, kernely = gaussian_kernel,
                   normalize = false)   # ≡ p_τ(y|x)

Estimand. The two-time transition density $p_\tau(y \mid x) = f_{X_{t+\tau} \mid X_t}(y \mid x)$ — the conditional density of the state a lag $\tau$ later, given the present state (nonstationary: $p_{t,\tau}$). For the Ornstein–Uhlenbeck process this is Gaussian in closed form.

Estimator. The conditional_density double-kernel estimator applied to the per-lag joint histogram of pairs $\bigl(X_t, X_{t+\tau}\bigr)$ (binned by observe_pairs! at the summary's lag $\tau$); the computation is identical — the name marks the two-time reading. A vector y returns the transition-density curve at the fixed present state x.

Arguments

  • summary — the per-lag joint Histogram2D of $(X_t, X_{t+\tau})$.
  • x — the present state, the conditioning value (a scalar).
  • y — the later state(s) at which the density is evaluated (a scalar, or a vector for the curve).
  • hx, hy — the conditioning ($x$) and response ($y$) bandwidths (both $> 0$), as for conditional_density.
  • kernelx, kernely — the conditioning and response kernels, as for conditional_density (an asymmetric kernely for a bounded / positive state).
  • normalize — as for conditional_density: true makes $\int \hat p_\tau(y\mid x)\,\mathrm dy = 1$ exact for an asymmetric kernely.
