ConditionalDensity

The conditional density conditional_density ($f_{Y\mid X}$) and the two-time transition density transition_density ($p_\tau(y\mid x)$, its subscript the lag) are estimated by a double kernel, a separate conditioning kernel_x and response kernel_y (see the Kernels page). Each has its pointwise standard error and a _with_standard_error reader returning both.

GBGStreamingStatistics.ConditionalDensity.conditional_density — Function
conditional_density(summary::Histogram2D, x, y; kernel_x = gaussian_kernel,
                    kernel_y = gaussian_kernel, h_x, h_y, normalize = false)

Estimand. The conditional density $f_{Y\mid X}(y \mid x) = f_{X,Y}(x, y) / f_X(x)$.

Estimator (double-kernel; Rosenblatt 1969; Hyndman, Bashtannyk & Grunwald 1996). From the joint Histogram2D summary, with a conditioning kernel $K_x$ (kernel_x, of bandwidth $h_x$ given by h_x, in $x$) and a response kernel $K_y$ (kernel_y, of bandwidth $h_y$ given by h_y, in $y$); both satisfy $\int K = 1$ and default to gaussian_kernel. Over the observed pairs of conditioning value and response, as many as the sample size, the estimator is

\[\hat f_{Y\mid X}(y \mid x) = \frac{\sum_i K_{h_x}(X_i - x) K_{h_y}(Y_i - y)}{\sum_i K_{h_x}(X_i - x)} ,\]

evaluated from the bin counts $n_{jl}$ at cell centers $(c^x_j, c^y_l)$ (the binned form, with $N_j = \sum_l n_{jl}$ the $x$-column count):

\[\hat f_{Y\mid X}(y \mid x) = \frac{\sum_{j,l} n_{jl} K_{h_x}(c^x_j - x) K_{h_y}(c^y_l - y)} {\sum_{j} N_j K_{h_x}(c^x_j - x)} .\]

Only the $x$-kernel's normalization cancels in the $f_{X,Y}/f_X$ ratio; its weighting sets the conditioning window, a degree-0 (Nadaraya–Watson-type) weighting that keeps a first-order bias at a bounded conditioning edge.

For a symmetric response kernel_y the surviving $1/h_y$ makes $\int \hat f_{Y\mid X}(y \mid x)\,\mathrm{d}y = 1$ exactly. For a bounded / positive response pass an asymmetric kernel_y (gamma_kernel for $[0,\infty)$, beta_kernel for $[0,1]$), the boundary-bias fix the marginal density uses: a density $K_y(c^y_l; y, b)$ in its data argument (the cell center), of scale $b$ set by h_y, so no mass leaks past the edge, but only approximately normalized in $y$; set normalize = true for $\int \hat f_{Y\mid X}\,\mathrm{d}y = 1$ exactly.

The conditional MISE falls as $O(n^{-2/3})$ in the sample size, slower than a marginal density's. A vector y returns the curve at the fixed conditioning value x; where no data is local to x the estimate is NaN.

Arguments

  • summary — the joint Histogram2D of $(X, Y)$.
  • x — the conditioning value (a scalar).
  • y — the response point(s) at which the density is evaluated (scalar, or a vector for the curve).
  • kernel_x — the $x$-direction kernel (default gaussian_kernel); its normalization cancels in the ratio; its weighting sets the window.
  • kernel_y — the $y$-direction kernel (default gaussian_kernel): symmetric, with $\int\hat f_{Y\mid X}\,\mathrm dy = 1$ exactly, or an asymmetric gamma_kernel / beta_kernel (or your own AsymmetricKernel) for a bounded / positive response, boundary-bias-free but needing normalize = true.
  • h_x, h_y — the conditioning ($x$) and response ($y$) bandwidths (both $> 0$), supplied.
  • normalize — when true, divide by $\int\hat f_{Y\mid X}(y\mid x)\,\mathrm dy$ over the response range so the curve integrates to 1 exactly: needed for an asymmetric kernel_y, a no-op for a symmetric one.
julia> g = Histogram2D(-1.0, 1.0, 2, -1.0, 1.0, 2);

julia> observe_pairs!(g, [0.4], [0.4]);   # one pair → cell with centers (0.5, 0.5)

julia> round(conditional_density(g, 0.5, 0.5; h_x = 0.5, h_y = 0.2); digits = 4)
1.9947

References

  • M. Rosenblatt (1969), Conditional probability density and regression estimators (no DOI), in Multivariate Analysis II, Academic Press.
  • R. J. Hyndman, D. M. Bashtannyk & G. K. Grunwald (1996), Estimating and visualizing conditional densities, J. Comput. Graph. Statist. 5(4).

GBGStreamingStatistics.ConditionalDensity.conditional_density_standard_error — Function
conditional_density_standard_error(summary::Histogram2D, x, y;
                                   kernel_x = gaussian_kernel,
                                   kernel_y = gaussian_kernel, h_x, h_y)

Estimand. The pointwise standard error of the conditional-density estimator conditional_density, $\operatorname{SE}(y\mid x) = \sqrt{\operatorname{Var}\hat f_{Y\mid X}(y\mid x)}$ with the double-kernel asymptotic variance

\[\operatorname{Var}\hat f_{Y\mid X}(y\mid x) \approx \frac{R(K_x)}{n h_x f_X(x)} \biggl[\frac{R(K_y) f_{Y\mid X}(y\mid x)}{h_y} - f_{Y\mid X}(y\mid x)^2\biggr], \qquad R(K) = \int K^2 .\]

Here $f_X$ is the marginal density of $X$; the bracket is the variance of one response-kernel term $K_{h_y}(Y - y)$, and $R(K_x)/(n h_x f_X(x))$ the sum of the squared weights of the samples near $x$.

Estimator. It is the two-term $\sqrt{R(K_x)/(h_x D) \cdot [R(K_y) \hat f_{Y\mid X}(y\mid x)/h_y - \hat f_{Y\mid X}(y\mid x)^2]}$ from the conditional density $\hat f_{Y\mid X}(y\mid x)$, the bandwidths $h_x$ (h_x) and $h_y$ (h_y), the kernel roughnesses $R(K_x)$, $R(K_y)$, and the $x$-window denominator $D = \sum_j N_j K_{h_x}(c^x_j - x) = n \hat f_X(x)$, the sum conditional_density normalizes by. It is the two-dimensional analog of density_standard_error, with the $x$-window effective sample size $n h_x \hat f_X(x)$ in place of the sample size $n$; the 95% band $\hat f_{Y\mid X}(y\mid x) \pm 1.96 \operatorname{SE}$ covers $f_{Y\mid X}$ where the $O(h^2)$ bias, in either bandwidth, is small. It takes symmetric kernels only (no asymmetric-kernel_y variance yet) and is NaN where no data is local to $x$.

Arguments: as for conditional_density, without normalize (the band is for the un-normalized estimate).

Reference: R. J. Hyndman, D. M. Bashtannyk & G. K. Grunwald (1996), Estimating and visualizing conditional densities, J. Comput. Graph. Statist. 5(4).

GBGStreamingStatistics.ConditionalDensity.conditional_density_with_standard_error — Function
conditional_density_with_standard_error(summary::Histogram2D, x, y;
                                        kernel_x = gaussian_kernel,
                                        kernel_y = gaussian_kernel, h_x, h_y)

Returns the estimate and its standard error from one $x$-profile reduction, the NamedTuple $(\texttt{value}, \texttt{standard\_error})$, with value the conditional_density $\hat f_{Y\mid X}(y\mid x)$ and standard_error its conditional_density_standard_error. They share the one profile, so they describe the same estimator by construction. For a vector y, returns a NamedTuple of vectors.

Arguments: as for conditional_density, without normalize (the band is for the un-normalized estimate); symmetric kernels only.

GBGStreamingStatistics.ConditionalDensity.transition_density — Function
transition_density(summary::Histogram2D, x, y; kernel_x = gaussian_kernel,
                   kernel_y = gaussian_kernel, h_x, h_y, normalize = false)

Estimand. The two-time transition density $p_\tau(y \mid x) = f_{Y(t+\tau) \mid X(t)}(y \mid x)$ — the conditional density of the state a lag $\tau$ later, given the present state ($p_{t,\tau}$ if it also depends on time). For the Ornstein–Uhlenbeck process this is Gaussian in closed form.

Estimator. The conditional_density double-kernel estimator applied to a joint histogram fed the pairs $\bigl(X(t), Y(t+\tau)\bigr)$ at one fixed lag $\tau$ (binned by observe_pairs!; the summary does not record the lag); the computation is identical — the name marks the two-time reading. A vector y returns the transition-density curve at the fixed present state x.

Arguments

  • summary — the per-lag joint Histogram2D of $(X(t), Y(t+\tau))$.
  • x — the present state, the conditioning value (a scalar).
  • y — the later state(s) at which the density is evaluated (a scalar, or a vector for the curve).
  • kernel_x, kernel_y — the conditioning and response kernels, as for conditional_density (an asymmetric kernel_y for a bounded / positive state).
  • h_x, h_y — the conditioning ($x$) and response ($y$) bandwidths (both $> 0$), as for conditional_density.
  • normalize — as for conditional_density: true makes $\int \hat p_\tau(y\mid x)\,\mathrm dy = 1$ exact for an asymmetric kernel_y.
