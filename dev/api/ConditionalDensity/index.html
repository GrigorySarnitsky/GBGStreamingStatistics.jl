ConditionalDensity

The conditional density conditional_density $\equiv f_{Y\mid X}$ and the two-time transition density transition_density $\equiv p_\tau(y\mid x)$ (§4.3).

GBGStreamingStatistics.ConditionalDensity.conditional_density — Function
conditional_density(summary::Histogram2D, x, y;
                    hx, hy, kernel = gaussian_kernel)   # ≡ f_{Y|X}

Estimand. the conditional density $f_{Y\mid X}(y \mid x) = f_{X,Y}(x, y) / f_X(x)$.

Estimator (double-kernel; Rosenblatt 1969; Hyndman, Bashtannyk & Grunwald 1996). From the joint Histogram2D summary, with a symmetric kernel $K$ ($\int K = 1$; default gaussian_kernel), conditioning bandwidth $h_1 =$ hx (in $x$) and response bandwidth $h_2 =$ hy (in $y$),

\[\hat f(y \mid x) = \frac{\sum_i K_{h_1}(X_i - x)\, K_{h_2}(Y_i - y)}{\sum_i K_{h_1}(X_i - x)} ,\]

evaluated from the bin counts $n_{jk}$ at cell centers $(c^x_j, c^y_k)$ (the binned form, with $N_j = \sum_k n_{jk}$ the per-column count):

\[\hat f(y \mid x) = \frac{\sum_{j,k} n_{jk}\, K_{h_1}(c^x_j - x)\, K_{h_2}(c^y_k - y)} {\sum_{j} N_j\, K_{h_1}(c^x_j - x)} .\]

The $x$-kernel weighting cancels in the ratio (it appears in both the profile and its total), leaving the $y$-direction normalization $1/h_2$; because $\int K = 1$ this makes $\int \hat f(y \mid x)\,\mathrm{d}y = 1$ for any such kernel. The conditional MISE rate is slower than a marginal density ($O(n^{-2/3})$). A vector y returns the density curve over those points at the fixed conditioning value x; where no data is local to x the estimate is NaN.

Arguments:

  • summary — the joint Histogram2D of $(X, Y)$.
  • x — the conditioning value (a scalar).
  • y — the response point(s) at which the density is evaluated (a scalar, or a vector for the curve).
  • hx, hy — the conditioning ($x$) and response ($y$) bandwidths (both $> 0$), supplied.
  • kernel — the symmetric smoothing kernel $K$ (any callable with $\int K = 1$; default gaussian_kernel), used in both directions.
julia> g = Histogram2D(-1.0, 1.0, 2, -1.0, 1.0, 2);

julia> observe_pairs!(g, [0.4], [0.4]);   # one pair → cell with centers (0.5, 0.5)

julia> round(conditional_density(g, 0.5, 0.5; hx = 0.5, hy = 0.2); digits = 4)
1.9947

References:

  • M. Rosenblatt (1969), Conditional probability density and regression estimators, in Multivariate Analysis II.
  • R. J. Hyndman, D. M. Bashtannyk & G. K. Grunwald (1996), Estimating and visualizing conditional densities, J. Comput. Graph. Statist. 5(4).

GBGStreamingStatistics.ConditionalDensity.transition_density — Function
transition_density(summary::Histogram2D, x, y;
                   hx, hy, kernel = gaussian_kernel)   # ≡ p_τ(y|x)

Estimand. the two-time transition density $p_\tau(y \mid x) = f_{X_{t+\tau} \mid X_t}(y \mid x)$ — the conditional density of the state a lag $\tau$ later, given the present state (nonstationary: $p_{t,\tau}$). For the Ornstein–Uhlenbeck oracle this is Gaussian in closed form (the natural end-to-end test).

Estimator. the conditional_density double-kernel estimator applied to the per-lag joint histogram of pairs $\bigl(X_t,\, X_{t+\tau}\bigr)$ (binned by observe_pairs! at the summary's lag $\tau$); the computation is identical — the name marks the two-time reading. The bandwidths hx (conditioning, in $x$), hy (response, in $y$), and the kernel are as for conditional_density. A vector y returns the transition-density curve at the fixed present state x.
