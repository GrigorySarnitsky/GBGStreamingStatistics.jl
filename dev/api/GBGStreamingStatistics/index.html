GBGStreamingStatistics

A backend-agnostic library for online nonparametric statistics: it estimates marginal densities, conditional expectations, conditional and two-time transition densities, and standard functionals of these, from a stream of samples that is never stored. Each sample is observed once, folded into a fixed-size summary, and discarded.

The summary is accumulated online and is response-agnostic; every reported quantity is a post-hoc smoothing functional of that one summary — so there is no storage of the underlying state and no recompute-from-raw reruns. The library is domain-neutral and model-neutral: it returns estimators and the diagnostics that test a model (the Pawula ratio, a Markov / Chapman–Kolmogorov test), never the model itself.

The package provides the mergeable accumulators and histogram carriers (observe!, observe_pairs!, merge!, Histogram1D, Histogram2D), the marginal density (density), conditional moments (conditional_mean, conditional_variance), conditional and transition densities (conditional_density, transition_density), the Kramers–Moyal functionals (increment_moment, kramers_moyal, drift, diffusion, pawula_quotient, markov_test), and bandwidth selection (bandwidth).
