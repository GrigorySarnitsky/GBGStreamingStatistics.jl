MarginalDensity

The marginal density $\equiv f_X$: the density estimator, its pointwise variability band density_standard_error and the paired density_with_standard_error, and the parametric starts for its semiparametric mode. density accepts any symmetric or bounded-support kernel from the Kernels page.

Density

GBGStreamingStatistics.MarginalDensity.density — Function
density(summary::Histogram1D, x; h = nothing, kernel = gaussian_kernel, degree = 0,
        adaptive = false, bounds = nothing, start = nothing, normalize = false,
        binning = :linear)   # ≡ f_X

Estimand. The marginal (Lebesgue) density $f_X = \mathrm{d}\mu_X/\mathrm{d}\lambda$ of the conditioning variable $X$, defined by $P(X \in A) = \int_A f_X\,\mathrm{d}\lambda$.

Estimator. The smoothed estimate $\hat f_h(x)$ from the accumulated summary — a binned local smoother of the counts $n_j$ at bin locations $\ell_j$ (the within-bin centroid by default; see the binning option), a KDE / WARPing, or a local-log-polynomial fit of $\log f$ at degree $\ge 1$.

Arguments:

  • summary — the Histogram1D of $X$.
  • x — the query point(s): a scalar for the density at one point, or a vector for the whole curve.
  • h — the smoothing bandwidth: the kernel scale, the one option that sets the bias–variance trade-off (larger h smooths more — less variance, more bias). Pass a positive number, or leave it nothing (default) to select one from the data by the kernel- and degree-aware normal-reference rule (bandwidth — Silverman's $(4/3)^{1/5}\hat\sigma n^{-1/5}$ for the Gaussian kernel at degree 0/1, wider at the $n^{-1/9}$ rate for degree 2). For a shape-adaptive choice, compute bandwidth(summary; rule = :sj) (or :isj / :aic) yourself and pass the number. The asymmetric gamma_kernel / beta_kernel take their own scale $b$ here (rate $n^{-2/5}$) in place of the symmetric h.
  • kernel — the smoothing weight $K$ (any callable with $\int K = 1$), default the symmetric gaussian_kernel. The compact-support symmetric epanechnikov_kernel and, for bounded / positive support, the asymmetric gamma_kernel ($[0,\infty)$, e.g. a droplet radius) and beta_kernel ($[0,1]$) — boundary-bias-free by construction — are catalogued with their supports and constants on the Kernels page; supply a custom AsymmetricKernel for your own bounded support. An asymmetric kernel is its own degree-0, boundary-free estimator, so degree, adaptive, bounds, and a parametric start do not combine with it, and it takes its own scale $b$ in place of h.
  • degree — the local-polynomial order. degree = 0 (default) is the binned KDE / WARPing (weighted averaging of rounded points) $\hat f(x) = \frac{1}{n} \sum_j (n_j/h_j) K((x-\ell_j)/h_j)$ ($\int K = 1$). degree $\ge 1$ is the local-log-polynomial (local-likelihood) estimator (Loader 1996): fit $\log f$ by a degree-degree polynomial through a binned local Poisson likelihood and report $\hat f(x) = e^{\hat\beta_0}$. degree = 1 (log-linear) is exact for an exponential density, so it tracks the exponential / stretched-exponential tails a flat KDE smears; degree = 2 (log-quadratic) is exact for a Gaussian. It falls back to the KDE where the local fit is degenerate or runs away in a sparse tail.
  • adaptive — whether the bandwidth varies with the local density. false (default) holds h fixed everywhere; true uses the Abramson variable bandwidth — the kernel width scales by $(\tilde f/g)^{-1/2}$ (a pilot $\tilde f$ at the bandwidth h, $g$ its geometric mean), widening in the sparse tails for far less tail variance (Abramson 1982). It is orthogonal to how h is chosen, so it composes with the data-driven bandwidth — pass h = bandwidth(summary; rule = :sj) to vary a shape-adaptive global scale locally (the chosen h becomes the Abramson pilot). (The degree-0 KDE uses the sample-point $h_j$ per bin; the local-log fit uses one balloon $h(x)$ at the query.)
  • bounds — the support of the density, passed as the tuple (lower, upper) (e.g. (0.0, Inf) for a positive quantity such as a droplet radius), or nothing (default, unbounded). When given, the degree-0 KDE is renormalized by the kernel mass inside the support: $\hat f(x) \big/ \int_a^b K_h(x-u)\,\mathrm{d}u$ (Jones 1993). This corrects the boundary bias that otherwise drops the estimate to $\approx$ half the true value at the edge. (degree $\ge 1$ is already boundary-adaptive, so bounds is a degree-0 option.)
  • start — a parametric start (Hjort & Glad 1995), or nothing (default). Given one, density returns the semiparametric estimate $\hat f(x) = p(x;\hat\theta) \frac{1}{nh}\sum_j \frac{n_j}{p(\ell_j;\hat\theta)} K((x-\ell_j)/h)$ — a moment-fitted model $p(\cdot;\hat\theta)$ times a KDE of its correction, near-exact wherever the start is correct (the correction is then $\equiv 1$) and degrading only to a bias-corrected KDE where it is not. $\hat\theta$ is fit by method of moments from the recovered $\hat\mu$, $\hat\sigma^2$, so the start is itself a functional of the summary. Pass a built-in normal_start, lognormal_start, gamma_start, exponential_start, or inverse_gaussian_start — the Parametric starts section lists each with its moment fit — or supply your own ParametricStart (a moment fit, a log-density, a support). It is a degree-0, fixed-h, symmetric-kernel estimator (degree $\ge 1$, adaptive, bounds, and the asymmetric kernels do not combine with it; use normalize for $\int\hat f = 1$).
  • normalize — when true, divide the estimate by $\int\hat f$ over the summary's range (intersected with the estimator's support), so $\int\hat f = 1$ exactly. The symmetric KDE already integrates to $\approx 1$; the asymmetric kernels and a parametric start do not, so this is their finishing step.
  • binning — where each bin's mass sits for the post-hoc evaluation. :linear (the default) places it at the recovered within-bin centroid $\ell_j = c_j + S_1^{(j)}/n_j$ (from the stored first power-sum $S_1$), which matches the bin's own first moment, so the binned estimate converges to the exact KDE at $O(\Delta^2)$ in the bin width $\Delta$; :simple places it at the geometric bin center $\ell_j = c_j$, the $O(\Delta)$ mass-at-center approximation. The centroid is read from data already in the summary, so the higher-order accuracy is free; it applies to every path (KDE, local-log, start, asymmetric kernel).

The four corners (fixed/variable $\times$ KDE/local-log) and everything between are one call. A vector of query points returns a vector.

julia> h = Histogram1D(-1.0, 1.0, 2);

julia> observe!(h, [0.4]);          # one sample at 0.4

julia> round(density(h, 0.4; h = 0.2); digits = 4)   # linear binning centers the bump at 0.4 (the centroid)
1.9947

References:

  • I. S. Abramson (1982), On bandwidth variation in kernel estimates—a square root law, Ann. Statist. 10(4) (variable bandwidth).
  • C. R. Loader (1996), Local likelihood density estimation, Ann. Statist. 24(4) (the local-log-polynomial estimator).
  • M. C. Jones (1993), Simple boundary correction for kernel density estimation, Statist. Comput. 3(3) (the bounds renormalization).
  • N. L. Hjort & I. K. Glad (1995), Nonparametric density estimation with a parametric start, Ann. Statist. 23(3) (the start estimator).

GBGStreamingStatistics.MarginalDensity.density_standard_error — Function
density_standard_error(summary::Histogram1D, x;
                       h = nothing, kernel = gaussian_kernel, degree = 0,
                       adaptive = false, bounds = nothing, start = nothing,
                       normalize = false, binning = :linear)   # ≡ SE[f̂(x)]

Estimand. The pointwise standard error of the density estimator density at $x$ — $\mathrm{SE}(x) = \sqrt{\operatorname{Var}\hat f_h(x)}$ with the kernel-density asymptotic variance

\[\operatorname{Var}\hat f_h(x) \approx \frac{R(K) f_X(x)}{n h} - \frac{f_X(x)^2}{n}, \qquad R(K) = \int K^2.\]

Estimator. $\sqrt{R(K) \hat f_h(x)/(n h) - \hat f_h(x)^2/n}$ from the recovered $\hat f_h(x)$, the count $n$, the bandwidth h (default the normal reference), and the roughness $R(K) = \int K^2$ of the smoothing kernel $K$ — any symmetric $\int K = 1$ callable, default gaussian_kernel — by quadrature. The pointwise variability band is $\hat f_h(x) \pm z \mathrm{SE}(x)$ ($z = 1.96$ for 95\%) — a band about $\mathbb{E}\hat f_h$, so it covers $f_X$ where the $O(h^2)$ smoothing bias is small and narrows that coverage at a sharp mode or in a tail.

It tracks the estimator's options — pass the same options you gave density and the band is the variance of that estimate (or use density_with_standard_error to get the estimate and its band from one call). The variance is adjusted per option: adaptive replaces $h$ by the local Abramson bandwidth $h(x)$ (a wider window — hence smaller variance — in the tail; the sample-point pilot's own variability is an unmodelled higher-order term, so the band runs slightly narrow in the deep tail); bounds (Jones renormalization) replaces $R(K)$ by the boundary-restricted roughness $R_a(x) = \frac{1}{h}\int_{\text{support}} K((x-u)/h)^2\,\mathrm du$ and divides by the squared in-support kernel mass $a(x)^2$, inflating the variance near an edge; a parametric start leaves the leading variance $R(K)\hat f/(nh)$ unchanged (the fitted-parameter uncertainty is an $O(1/n)$ omission). Restricted to degree 0/1 and a symmetric kernel (degree $\ge 2$ and an asymmetric gamma/beta kernel are not supported); a vector of query points returns a vector.

Arguments: as for density — h, kernel, degree, adaptive, bounds, start, normalize, binning — specifying the estimator whose standard error is returned.

julia> h = Histogram1D(-6.0, 6.0, 600);

julia> observe!(h, [-0.4, 0.1, 0.2, 0.9, 1.3]);

julia> density_standard_error(h, 0.5) > 0
true

Reference: M. P. Wand & M. C. Jones (1995), Kernel Smoothing, Chapman & Hall.

GBGStreamingStatistics.MarginalDensity.density_with_standard_error — Function
density_with_standard_error(summary::Histogram1D, x;
                            h = nothing, kernel = gaussian_kernel, degree = 0,
                            adaptive = false, bounds = nothing, start = nothing,
                            normalize = false, binning = :linear)

The density estimate and its pointwise density_standard_error, from a single option specification — so the estimate and its error describe the same estimator by construction (the estimate is computed once and reused). Returns the NamedTuple (value = f̂(x), standard_error = SE(x)); a vector x gives a (value, standard_error) of vectors. All options are exactly those of density; the standard error's estimand and per-option variance are documented at density_standard_error.

julia> h = Histogram1D(-6.0, 6.0, 600);

julia> observe!(h, [-0.4, 0.1, 0.2, 0.9, 1.3]);

julia> r = density_with_standard_error(h, 0.5); (r.value > 0, r.standard_error > 0)
(true, true)

Parametric starts

The moment-fitted ParametricStart models for the Hjort–Glad semiparametric density(…; start = …), each documented below.

GBGStreamingStatistics.MarginalDensity.normal_start — Constant
normal_start

A Gaussian (normal) ParametricStart on $(-\infty,\infty)$: $p(x;\hat\mu,\hat\sigma^2)$ with $\hat\mu$, $\hat\sigma^2$ the recovered sample mean and variance. Pass start = normal_start to density.

source
GBGStreamingStatistics.MarginalDensity.lognormal_start — Constant
lognormal_start

A log-normal ParametricStart on $(0,\infty)$, parameters by method of moments ($s^2 = \log(1+\hat\sigma^2/\hat\mu^2)$, $m = \log\hat\mu - s^2/2$). A natural start for a positively skewed quantity such as a droplet radius; pass start = lognormal_start.

source
GBGStreamingStatistics.MarginalDensity.gamma_start — Constant
gamma_start

A gamma ParametricStart on $(0,\infty)$, shape $k = \hat\mu^2/\hat\sigma^2$ and scale $\theta = \hat\sigma^2/\hat\mu$ by method of moments. For a non-negative quantity; pass start = gamma_start.

source
GBGStreamingStatistics.MarginalDensity.exponential_start — Constant
exponential_start

An exponential ParametricStart on $[0,\infty)$, rate $\hat\lambda = 1/\hat\mu$ (a one-parameter start fit from the mean alone). Pass start = exponential_start; pairs with the degree = 1 log-linear fit as the two exponential-tail tools.

source
GBGStreamingStatistics.MarginalDensity.inverse_gaussian_start — Constant
inverse_gaussian_start

An inverse-Gaussian ParametricStart on $(0,\infty)$, mean $\hat\mu$ and shape $\hat\lambda = \hat\mu^3/\hat\sigma^2$ by method of moments — a positive start with an exponentially decaying right tail (lighter than the log-normal's). Pass start = inverse_gaussian_start.

source
GBGStreamingStatistics.MarginalDensity.ParametricStart — Type
ParametricStart(fit, logpdf, support)

A parametric start for the Hjort–Glad semiparametric density (Hjort & Glad 1995). Passed as density(…; start = …), it multiplies the moment-fitted model $p(\cdot;\hat\theta)$ by a kernel estimate of the correction $f_X/p$ — near-exact where the model fits (the bias is driven by $(f_X/p)''$, not $f_X''$), degrading only to a kernel-of-the-ratio bias where it does not. The built-ins are normal_start, lognormal_start, gamma_start, exponential_start, and inverse_gaussian_start; construct one directly to plug in a custom parametric model. The three fields are the construction contract:

  • fit(mean, variance) — fit the model parameters from the recovered moments by method of moments, returning a parameter tuple. Fitting from the mean and variance (not the raw data) is what keeps the whole estimate mergeable: $\hat\theta$ is itself a post-hoc functional of the summary.
  • logpdf(x, params) — the model log-density $\log p(x;\hat\theta)$, returning $-\infty$ off the support. density reweights each bin by $1/p(\ell_j;\hat\theta)$ at the bin location $\ell_j$ through this log form (stable in the tails, where $p$ is tiny).
  • support — the domain the model is positive on, as a (lower, upper) tuple (e.g. (0.0, Inf)).
julia> rayleigh = ParametricStart(
           (mean, variance) -> (mean * sqrt(2 / π),),                            # σ from the mean
           (x, p) -> x > 0 ? log(x) - 2 * log(p[1]) - x^2 / (2 * p[1]^2) : -Inf,  # Rayleigh log-density
           (0.0, Inf));

julia> rayleigh isa ParametricStart
true

Reference: N. L. Hjort & I. K. Glad (1995), Nonparametric density estimation with a parametric start, Ann. Statist. 23(3).
