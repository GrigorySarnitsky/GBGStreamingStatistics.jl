ConditionalExpectations

The conditional expectation $\mathbb{E}[g(Y) \mid X = x]$ of a smooth functional of the response (conditional_expectation) with its sampling standard error (conditional_expectation_standard_error, paired with the estimate by conditional_expectation_with_standard_error), the conditional mean conditional_mean ($m(x)$) and variance conditional_variance ($\sigma^2(x)$, with its residual-based standard error) as its $g = \mathrm{identity}$ / $y^2$ cases, and the conditional pushforward density conditional_pushforward_density ($f_{g(Y) \mid X}$) of a transformed response. All are local-polynomial regressions in $x$ of a $y$-quadrature response (the per-column expectation of the functional, read off the stored response power-sums).

GBGStreamingStatistics.ConditionalExpectations.conditional_expectation — Function
conditional_expectation(summary::Histogram2D, g, x;   # ≡ 𝔼[g(Y) | X = x]
                        kernel = gaussian_kernel,
                        degree = kernel isa AsymmetricKernel ? 0 : 1, h)

Estimand. The conditional expectation of a smooth functional of the response, $\mathbb{E}[g(Y) \mid X = x] = \int g(y) f_{Y\mid X}(y \mid x)\,\mathrm{d}y$. For $g = \mathrm{identity}$ this is the regression function $m(x)$ (conditional_mean); for $g(y) = y^2$ it is $\mathbb{E}[Y^2 \mid X = x]$, the plug-in ingredient of conditional_variance.

Estimator. The estimate is a local-polynomial regression in $x$ of a per-$x$-column $y$-quadrature of $g$. Per $x$-column (a conditioning bin) the response $\sum_i g(Y_i)$ is recovered from the stored order-2 $y$-power-sums (per-cell sums of the response and its square; exact for $g$ of degree $\le 2$) by the marginal expectation's quadrature, then smoothed across $x$ by a local-polynomial fit of order degree; the estimate is the fitted value $\hat\beta_0$. It thus applies kernel-weighting in $x$ after power-sum quadrature in $y$, and reduces to conditional_mean at $g = \mathrm{identity}$.

Because a Histogram2D stores only the order-2 $y$-power-sums, the $y$-quadrature is exact for $g$ of degree $\le 2$ in $y$ (so $\mathbb{E}[Y \mid X = x]$ and $\mathbb{E}[Y^2 \mid X = x]$ are exact) and $O(\Delta_y^2)$ for a general smooth $g$. The $x$-side carries the local-polynomial bias/variance of conditional_mean. A vector of query points returns a vector, NaN where no data is local to $x$.

Arguments

  • summary — the joint Histogram2D of $(X, Y)$.
  • g — the response functional to average: any callable $y \mapsto g(y)$ (smooth on the $y$-bin scale). g = identity gives the conditional mean, g = abs2 the conditional $\mathbb{E}[Y^2 \mid X = x]$.
  • x — the conditioning value(s) where the expectation is evaluated (scalar or vector).
  • kernel — the conditioning ($x$) kernel: any $\int K = 1$ callable (default gaussian_kernel) or an AsymmetricKernel (gamma_kernel / beta_kernel, for bounded conditioning).
  • degree — the local-polynomial order in $x$: 0 (Nadaraya–Watson), 1 (local-linear), or 2. The default is 1, or 0 under an asymmetric kernel (which fits no polynomial — no jet).
  • h — the conditioning ($x$) bandwidth ($h > 0$), supplied.

Reference: J. Fan & I. Gijbels (1996), Local Polynomial Modelling and Its Applications, Chapman & Hall.

GBGStreamingStatistics.ConditionalExpectations.conditional_expectation_standard_error — Function
conditional_expectation_standard_error(summary::Histogram2D, g, x;
                                       kernel = gaussian_kernel,
                                       degree = kernel isa AsymmetricKernel ? 0 : 1,
                                       h)

Estimand. The sampling standard error of the estimator conditional_expectation, $\operatorname{SE}\bigl(\widehat{\mathbb{E}}[g(Y)\mid X = x]\bigr) = \sqrt{\ell(x) \operatorname{Var}(g(Y)\mid X = x)}$, with the local-regression leverage $\ell(x) = \sum_j N_j \omega_j(x)^2$ ($N_j$ the per-$x$-column count, $\omega_j$ the effective weights of the fit's $\hat\beta_0$) and the conditional variance of the transformed response $\operatorname{Var}(g(Y)\mid X = x) = \mathbb{E}[g(Y)^2\mid X = x] - \mathbb{E}[g(Y)\mid X = x]^2$.

Estimator. The estimate is the leverage times the noise scale, $\sqrt{\hat\ell(x) (\widehat{\mathbb{E}}[g^2\mid X = x] - \widehat{\mathbb{E}}[g\mid X = x]^2)}$: the leverage $\hat\ell(x)$ of the local fit (correct at any degree) times the plug-in conditional variance of $g(Y)$ — itself two evaluations of conditional_expectation ($\mathbb{E}[g^2\mid X = x]$ with $g^2$ for the functional). This is the analog of the marginal expectation_standard_error, $\sqrt{\operatorname{Var}(g(X)) / n}$, with the global-mean leverage $1/n$ replaced by the local $\sum_j N_j \omega_j^2$; at $g = \mathrm{identity}$ it is the standard error of the conditional mean $m(x)$. It is the plug-in sampling error (not the $O(h^2)$ smoothing bias). It is NaN where no data is local to $x$.

Arguments: as for conditional_expectation.

They describe the same estimator by construction, their $y$-quadrature responses fitted on one design. For a vector x, returns a NamedTuple of vectors.

GBGStreamingStatistics.ConditionalExpectations.conditional_mean — Function
conditional_mean(summary::Histogram2D, x; kernel = gaussian_kernel,
                 degree = kernel isa AsymmetricKernel ? 0 : 1, h)   # ≡ m(x)

Estimand. The conditional expectation $m(x) = \mathbb{E}[Y \mid X = x] = \int y f_{Y\mid X}(y \mid x)\,\mathrm{d}y$ — the $L^2(\mathbb{P}_X)$ projection of the response $Y$ onto the conditioning variable $X$, i.e. the regression function.

Estimator (local-polynomial; Fan & Gijbels 1996). From the joint summary (a Histogram2D of $(X, Y)$) form the kernel-weighted design and response sums $U_p(x) = \sum_i K_h(X_i-x)(X_i-x)^p$ and $V_p(x) = \sum_i K_h(X_i-x)(X_i-x)^p Y_i$ — recovered from the per-x-column counts and response totals $\sum Y$ (themselves exact, from the per-cell power-sums) — and solve the local normal equations of order degree for the jet $(\hat\beta_0, \dots, \hat\beta_{\texttt{degree}})$ — the local-polynomial coefficients at $x$ ($\hat\beta_0$ the fitted value, $\hat\beta_1$ the slope, $2\hat\beta_2$ the curvature); the estimate is the fitted value $\hat m_h(x) = \hat\beta_0$. At the default degree = 1 (local-linear) this is

\[\hat m_h(x) = \frac{U_2 V_0 - U_1 V_1}{U_0 U_2 - U_1^{2}},\]

which removes the design-density bias $2 m'(x) f_X'(x)/f_X(x)$ of the Nadaraya–Watson reduction $\hat m_h = V_0/U_0$ (the degree = 0 local-constant fit). The bandwidth $h$ is supplied (or the response-aware local plug-in $h^\star(x)$ from bandwidth(summary, x; rule = :local)); degree = 2 (local-quadratic) additionally exposes the curvature $\hat m''(x)$ that $h^\star(x)$ needs. A vector of query points returns a vector. Consistency: $\operatorname{bias}\hat m_h(x) \approx \tfrac{1}{2} h^2 \mu_2(K) m''(x)$, $\operatorname{Var}\hat m_h(x) \approx R(K) \sigma^2(x)/(n h f_X(x))$.

Boundary adaptivity. The local-linear fit (degree = 1, the default) is boundary-adaptive (Fan & Gijbels 1996): conditioning on a bounded or positive quantity — a droplet radius $X \ge 0$, say — is first-order correct near the edge with the symmetric kernel, because the local-linear fit corrects the $O(h)$ boundary bias to the interior $O(h^2)$ automatically. The degree = 0 Nadaraya–Watson fit does not — it keeps the $O(h)$ edge bias — so near a bounded edge use degree = 1 (the default; being local-linear it is also unbiased for a linear mean). A degree = 0 asymmetric kernel (gamma_kernel / beta_kernel) is admitted too — the uniform degree-0 boundary kernel, no jet, so degree = 0 only — but these boundary kernels are a density tool whose asymmetry interacts with the regression design density, so they do not generally improve the conditional mean; prefer degree = 1 for a bounded conditioning variable. A bounded response is the other case: there the response kernel can be asymmetric — see conditional_density.

Arguments

  • summary — the joint Histogram2D of $(X, Y)$.
  • x — the conditioning value(s) at which $m$ is evaluated (a scalar for one point, or a vector for the whole curve).
  • kernel — the smoothing kernel: a symmetric callable $K$ ($\int K = 1$; default gaussian_kernel, at any degree), or an asymmetric gamma_kernel / beta_kernel for a bounded/positive conditioning variable (degree = 0 only).
  • degree — the local-polynomial order: 0 (Nadaraya–Watson), 1 (local-linear), or 2 (local-quadratic). The default is 1, or 0 under an asymmetric kernel, which fits no polynomial (no jet) and admits only 0.
  • h — the smoothing bandwidth ($h > 0$), supplied.

Reference: J. Fan & I. Gijbels (1996), Local Polynomial Modelling and Its Applications, Chapman & Hall.

GBGStreamingStatistics.ConditionalExpectations.conditional_variance — Function
conditional_variance(summary::Histogram2D, x; kernel = gaussian_kernel,
                     degree = kernel isa AsymmetricKernel ? 0 : 1, h,
                     method = :residual)   # ≡ σ²(x)

Estimand. The conditional variance $\sigma^2(x) = \operatorname{Var}(Y \mid X = x) = \mathbb{E}[Y^2 \mid X = x] - m(x)^2$, with $m(x)$ the conditional_mean.

Estimator (method = :residual, the default — Fan & Yao 1998). The two-stage residual-based estimator: fit $\hat m$ at each x-column center, then take a second local fit of the per-column squared residuals, $\hat\sigma^2(x) = \widehat{\mathbb{E}}\bigl[(Y - \hat m(X))^2 \mid X = x\bigr]$. Because $\mathbb{E}[(Y - m(X))^2 \mid X = x] = \sigma^2(x)$ is far flatter than $\mathbb{E}[Y^2 \mid X = x]$, its local fit is much less biased — it removes the local-polynomial smoothing bias of the curved $\mathbb{E}[Y^2 \mid X = x]$ that the plug-in carries. The squared-residual total of $x$-column $j$ is recovered exactly from the stored column sums, $\sum Y^2 - 2\hat m \sum Y + \hat m^2 N_j$.

Estimator (method = :plugin). The estimate is the difference $\widehat{\mathbb{E}}[Y^2 \mid X = x] - \hat m_h(x)^2$ (the same local fit applied to the $Y^2$ response), clamped non-negative; cheaper (no first stage), it carries the curved-$\mathbb{E}[Y^2 \mid X = x]$ smoothing bias. A vector x returns a vector, NaN where no data is local.

Arguments

  • summary — the joint Histogram2D of $(X, Y)$.
  • x — the conditioning value(s) at which $\sigma^2$ is evaluated (scalar or vector).
  • kernel — the smoothing kernel $K$ (any callable with $\int K = 1$; default gaussian_kernel).
  • degree — the local-polynomial order for the underlying fits: 0, 1, or 2. The default is 1, or 0 under an asymmetric kernel, which fits no polynomial (no jet) and admits only 0.
  • h — the smoothing bandwidth ($h > 0$), supplied.
  • method — :residual (the default, the bias-reduced Fan & Yao two-stage estimator) or :plugin (the simple $\widehat{\mathbb{E}}[Y^2 \mid X = x] - \hat m^2$ difference).

References

  • J. Fan & Q. Yao (1998), Efficient estimation of conditional variance functions in stochastic regression, Biometrika 85(3) (the residual-based estimator).
  • J. Fan & J. Jiang (2000), Variable bandwidth and one-step local M-estimator, Sci. China Ser. A 43 (a robust one-step M-estimator refinement, not offered).

GBGStreamingStatistics.ConditionalExpectations.conditional_variance_standard_error — Function
conditional_variance_standard_error(summary::Histogram2D, x;
                                    kernel = gaussian_kernel,
                                    degree = kernel isa AsymmetricKernel ? 0 : 1,
                                    h)

Estimand. The sampling standard error of the conditional variance conditional_variance, $\operatorname{SE}(\hat\sigma^2(x)) = \sqrt{\ell(x) \bigl(\mu_4(x) - \sigma^4(x)\bigr)}$ with the local-regression leverage $\ell(x)$, the conditional variance $\sigma^2(x)$, and the 4th central conditional moment $\mu_4(x) = \mathbb{E}[(Y - m(x))^4 \mid X = x]$.

Estimator. The residual approximation: since $\hat\sigma^2(x)$ is a conditional mean of the squared residual $(Y - \hat m(x))^2$, its standard error is the conditional_expectation_standard_error of that response, $\sqrt{\hat\ell(x) (\hat\mu_4(x) - \hat\sigma^4(x))}$, with $\hat\mu_4$ the $y$-quadrature of the smooth $(Y - \hat m(x))^4$ off the order-2 $y$-power-sums — so the $O(\Delta_y^2)$ quadrature captures the conditional kurtosis (a heavy-tailed response widens the band) with no 4th-moment storage. It is the leading-order SE common to both variance methods. A vector x returns a vector, NaN where no data is local.

Arguments: as for conditional_variance, without method (the leading-order SE is common to :residual and :plugin).

GBGStreamingStatistics.ConditionalExpectations.conditional_pushforward_density — Function
conditional_pushforward_density(summary::Histogram2D, g, x, z;   # ≡ f_{g(Y)|X}
                                kernel_x = gaussian_kernel,
                                kernel_z = gaussian_kernel,
                                degree = kernel_x isa AsymmetricKernel ? 0 : 1, h_x,
                                h_z)

Estimand. The density of the transformed response $Z = g(Y)$ given $X = x$ — the conditional pushforward, change of variables applied to the conditional law, $f_{g(Y)\mid X}(z \mid x) = \sum_{y: g(y)=z} f_{Y\mid X}(y \mid x) / |g'(y)|$.

Estimator. The estimate is the conditional kernel density of $g(Y)$, written as a conditional expectation and evaluated by conditional_expectation:

\[\hat f_{g(Y)\mid X}(z \mid x) = \widehat{\mathbb{E}}\bigl[ K_{h_z}(g(Y) - z) \mid X = x \bigr] ,\]

i.e. conditional_expectation of the composed kernel. No inverse $g^{-1}$ and no explicit Jacobian is formed; a non-monotone $g$ contributes from every preimage automatically, $g'=0$ is an integrable caustic, and a symmetric response kernel $K_z$ (kernel_z, $\int K = 1$) makes $\int \hat f_{g(Y)\mid X}\,\mathrm dz = 1$ exactly. It smooths in two directions: the $x$-conditioning regression (h_x, kernel_x, degree — degree-aware in $x$, unlike the degree-0 double-kernel conditional_density) and the $z$ smoothing (h_z, kernel_z). At $g = \mathrm{identity}$ with degree = 0 it agrees with conditional_density to second order in the response bin width (the within-cell correction) — the native estimator for the untransformed response (with the bounded-response asymmetric kernel_y and normalize). Needs $g$ smooth on the $y$-bin scale and the response bandwidth $h_z \gtrsim |g'| \Delta_y$. A vector z returns the curve at the fixed conditioning value x.

Arguments

  • summary — the joint Histogram2D of $(X, Y)$.
  • g — the transform defining $Z = g(Y)$ (any callable, smooth on the $y$-bin scale).
  • x — the conditioning value (a scalar).
  • z — the transformed-response point(s) at which the density is evaluated (scalar, or a vector for the curve).
  • kernel_x — the conditioning ($x$) kernel (any $\int K = 1$ callable; default gaussian_kernel).
  • kernel_z — the response-direction ($z$) kernel (default gaussian_kernel; a symmetric one integrates to 1 exactly).
  • degree — the local-polynomial order in $x$: 0, 1, or 2. The default is 1, or 0 under an asymmetric kernel_x, which fits no polynomial (no jet) and admits only 0.
  • h_x, h_z — the conditioning ($x$) and transformed-response ($z$) bandwidths (both $> 0$), supplied.

Reference: B. W. Silverman (1986), Density Estimation for Statistics and Data Analysis, Chapman & Hall.

GBGStreamingStatistics.ConditionalExpectations.conditional_pushforward_density_standard_error — Function
conditional_pushforward_density_standard_error(summary::Histogram2D, g, x, z;
    kernel_x = gaussian_kernel, kernel_z = gaussian_kernel,
    degree = kernel_x isa AsymmetricKernel ? 0 : 1, h_x, h_z)

Estimand. The estimand is the pointwise standard error of the conditional pushforward density conditional_pushforward_density $\equiv f_{g(Y)\mid X}$, the sampling error of the density of the transformed response $g(Y)$ at $z$ given $x$.

Estimator. The band is the two-term $\sqrt{\hat\ell(x) [R(K_z)\hat f_{g(Y)\mid X}/h_z - \hat f_{g(Y)\mid X}^2]}$: the local-regression leverage $\hat\ell(x)$ of the fit in $x$ (correct at any degree) times the variance of the response $K_{h_z}(g(Y) - z)$ — $R(K_z) = \int K_z^2$ by quadrature, the analytic form since the order-2 $y$-quadrature cannot resolve the squared narrow kernel $K_{h_z}^2$. At degree 0 it reduces asymptotically to the conditional_density_standard_error of the transformed response. Only a symmetric kernel_z is supported.

Arguments: as for conditional_pushforward_density.
