Kernels

The smoothing kernels come in two families; every estimator applies one to a summary, the binned histogram of the stream. The symmetric kernels are any callable kernel with $\int K = 1$ (the kernel-aware bandwidth computes its roughness $R(K)$ and second moment $\mu_2(K)$ by quadrature, so a custom one needs no manual constants). The asymmetric varying-shape kernels — gamma_kernel for $[0,\infty)$, beta_kernel for $[0,1]$, or a custom AsymmetricKernel — match a bounded / positive support and are boundary-bias-free by construction (Chen 1999, 2000). Both families feed the estimators as kernel = …: the marginal density, the conditional_density (as kernel_y), the conditional_expectation, and the bandwidth rules.

Symmetric

GBGStreamingStatistics.Kernels.gaussian_kernel — Function
gaussian_kernel(u)

The standard Gaussian smoothing kernel $K(u) = e^{-u^2/2}/\sqrt{2\pi}$ ($\int K = 1$, second moment $\mu_2(K) = 1$, roughness $R(K) = 1/(2\sqrt{\pi})$) is the density default.

GBGStreamingStatistics.Kernels.epanechnikov_kernel — Function
epanechnikov_kernel(u)

The Epanechnikov kernel $K(u) = \tfrac{3}{4}(1 - u^2)$ for $|u| \le 1$ (zero outside) is the MSE-optimal second-order kernel ($\int K = 1$, second moment $\mu_2(K) = 1/5$, roughness $R(K) = 3/5$). Pass it as kernel = epanechnikov_kernel to density; its compact support touches only the bins within the bandwidth $h$ of the query point. The bandwidth selector is kernel-aware, so it returns the matched Epanechnikov scale directly.

Asymmetric (bounded / positive support)

GBGStreamingStatistics.Kernels.gamma_kernel — Constant
gamma_kernel

The gamma kernel (Chen 2000) estimates a density on the half-line $[0,\infty)$ as an asymmetric kernel: at the query point $x$ it is the modified $\mathrm{Gamma}(\rho(x), b)$ density in the data argument, with the bandwidth (the keyword h) as its scale. Chen's bias-reduced shape is $\rho(x) = x/b$ in the interior, so the kernel mean is exactly $x$, removing the slope $f_X'$ from the bias of the naive $x/b+1$ shape, and $(x/b)^2/4 + 1$ within $2b$ of the edge.

With kernel = gamma_kernel, density returns the estimate from the bin counts at the bin locations, with $O(b)$ bias uniformly, also at the boundary, where a symmetric kernel is inconsistent; the variance grows toward the edge. Use it for non-negative data, usually sharper than the support renormalization of density. The bandwidth defaults to $\hat\sigma_X n^{-2/5}$, the sample standard deviation times the sample-size rate; override it with h, or use the Chen plug-in bandwidth(summary; rule = :plugin, kernel = gamma_kernel), which lowers the ISE on skewed data. The local-polynomial degree, variable-bandwidth adaptive and support options of density do not apply: the kernel is its own degree-0 estimator.

Reference: S. X. Chen (2000), Probability density function estimation using gamma kernels, Ann. Inst. Statist. Math. 52(3).

GBGStreamingStatistics.Kernels.beta_kernel — Constant
beta_kernel

The beta kernel (Chen 1999) estimates a density on $[0,1]$ as the bounded-interval analog of gamma_kernel: at $x$ it is the modified $\mathrm{Beta}$ density in the data argument, boundary-bias-free at both edges, with the bandwidth (the keyword h) as its scale $b$. Its interior shapes are $(x/b, (1-x)/b)$; within $2b$ of the left edge the first becomes $\rho(x) = 2b^2 + 5/2 - \sqrt{4b^4 + 6b^2 + 9/4 - x^2 - x/b}$, and within $2b$ of the right edge the second becomes $\rho(1-x)$. Pass kernel = beta_kernel with data scaled to $[0,1]$; bandwidth default, option restrictions and the $n^{-2/5}$ rate are as for gamma_kernel.

Reference: S. X. Chen (1999), Beta kernel estimators for density functions, Comput. Statist. Data Anal. 31(2).

GBGStreamingStatistics.Kernels.AsymmetricKernel — Type
AsymmetricKernel(pdf, support; local_scale_weight = nothing)

A varying-shape asymmetric kernel for density on a bounded or half-line support is the boundary-bias-free analog of a symmetric smoothing kernel (Chen 1999, 2000). The built-ins are gamma_kernel for $[0,\infty)$ and beta_kernel for $[0,1]$; construct one directly to plug in a custom boundary kernel and its local-scale weight $w(x)$ for the plug-in bandwidth.

Arguments

The constructor takes the three fields, the last as a keyword:

  • pdf(v, x, b) — the kernel as a density in the data argument $v$, whose shape is set by the evaluation point $x$ and bandwidth $b$ (normalized: $\int \texttt{pdf}(v, x, b)\,\mathrm{d}v = 1$ over the support, for each $x$ and $b$). density sums it over the bin counts at the bin locations, so merged summaries give the same estimate.
  • support — the data domain the kernel covers, as a (lower, upper) tuple (e.g. (0.0, Inf)).
  • local_scale_weight — the AMISE local-scale weight $w(x)$, a callable x -> w(x): the leading bias is $\tfrac{1}{2} b w(x) f_X''(x)$ and the interior variance $\propto w(x)^{-1/2}$ ($w(x) = x$ for the gamma kernel, $x(1-x)$ for the beta). Only bandwidth(…; rule = :plugin) uses it. If it is unset (nothing, the default), rule = :plugin errors, while the $\hat\sigma_X n^{-2/5}$ rule of thumb (rule = :normal, from the sample standard deviation) needs no weight.
using SpecialFunctions: loggamma
# the built-in gamma kernel, as a template (the shape of Chen's bias-reduced
# estimator); the AMISE weight w(x) = x serves rule = :plugin
mygamma = AsymmetricKernel(
    (v, x, b) -> v > 0 ?
        (ρ = x < 2b ? (x / b)^2 / 4 + 1 : x / b;
         exp((ρ - 1) * log(v) - v / b - ρ * log(b) - loggamma(ρ))) : 0.0,
    (0.0, Inf);
    local_scale_weight = x -> x)
# summary: a Histogram1D of the stream, accumulated with observe!
density(summary, 1.0; kernel = mygamma)

References

  • S. X. Chen (1999), Beta kernel estimators for density functions, Comput. Statist. Data Anal. 31(2).
  • S. X. Chen (2000), Probability density function estimation using gamma kernels, Ann. Inst. Statist. Math. 52(3).

Fields

  • pdf — the kernel, a callable (v, x, b) giving a density in the data argument.
  • support — the data domain the kernel covers, a (lower, upper) tuple.
  • local_scale_weight — the AMISE local-scale weight, a callable, or nothing when unset.
