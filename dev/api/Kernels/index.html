Kernels

The symmetric smoothing kernels shared across the estimators — any callable with $\int K = 1$ works (the kernel-aware bandwidth computes its roughness $R(K)$ and second moment $\mu_2(K)$ by quadrature, so a custom symmetric kernel needs no manual constants). Two ship; the bounded/positive-support asymmetric kernels live with MarginalDensity.

GBGStreamingStatistics.Kernels.gaussian_kernel — Function
gaussian_kernel(u)

The standard Gaussian smoothing kernel $K(u) = e^{-u^2/2}/\sqrt{2\pi}$ ($\int K = 1$, second moment $\mu_2(K) = 1$, roughness $R(K) = 1/(2\sqrt{\pi})$) — the density default.

GBGStreamingStatistics.Kernels.epanechnikov_kernel — Function
epanechnikov_kernel(u)

The Epanechnikov kernel $K(u) = \tfrac{3}{4}(1 - u^2)$ for $|u| \le 1$ (zero outside) — the MSE-optimal second-order kernel ($\int K = 1$, second moment $\mu_2(K) = 1/5$, roughness $R(K) = 3/5$). Pass it as kernel = epanechnikov_kernel; its compact support touches only the bins within $h$ of the query point. bandwidth is kernel-aware, so it returns the matched Epanechnikov $h \approx 2.34\,\hat\sigma\,n^{-1/5}$ ($2.21\times$ the Gaussian $h$) automatically — no manual rescaling.
