DensityEstimation

The marginal density density $\equiv f_X$ (§4.1).

GBGStreamingStatistics.DensityEstimation.density — Method
density(summary::Histogram1D, x; h, kernel = gaussian)   # ≡ f_X

Estimand. the marginal (Lebesgue) density $f_X = \mathrm{d}\mu_X/\mathrm{d}\lambda$ of the conditioning variable $X$, defined by $P(X \in A) = \int_A f_X\,\mathrm{d}\lambda$.

Estimator (binned KDE / WARPing). From the bin counts $n_j$ at centers $c_j$ of summary (a Histogram1D), the total count $n$, and a kernel $K$ with $\int K = 1$ and bandwidth $h$,

\[\hat f_h(x) = \frac{1}{n\,h} \sum_{j} n_j\, K\!\left(\frac{x - c_j}{h}\right),\]

the binned approximation to $\frac{1}{nh}\sum_i K\!\left(\frac{x - X_i}{h}\right)$ (Hall & Wand 1996). The bandwidth $h$ comes from bandwidth (or is supplied directly); kernel defaults to the standard Gaussian. Here the convolution is a direct sum over occupied bins; the FFT amortization of the sum over a whole bandwidth grid is forthcoming (CLAUDE.md roadmap). A vector of query points returns a vector of densities.

julia> h = Histogram1D(-1.0, 1.0, 2);

julia> observe!(h, [0.4]);          # one sample, binned at center 0.5

julia> round(density(h, 0.5; h = 0.2); digits = 4)
1.9947
