DensityEstimation

The marginal density density $\equiv f_X$ (§4.1).

GBGStreamingStatistics.DensityEstimation.beta_kernel — Constant
beta_kernel

The beta kernel (Chen 1999) for a density on the unit interval $[0,1]$ — the bounded-interval analog of gamma_kernel: at $x$ it is the modified (bias-reduced) $\mathrm{Beta}$ density in the data argument (Chen's $f_2$: interior shapes $(x/b,\,(1-x)/b)$, with a $\sqrt{\,\cdot\,}$ correction within $2b$ of an edge), boundary-bias-free at both edges. Pass kernel = beta_kernel with data scaled to $[0,1]$; the bandwidth default, the knob restrictions, and the $n^{-2/5}$ rate are as for gamma_kernel.

Reference: S. X. Chen (1999), Beta kernel estimators for density functions, Comput. Statist. Data Anal. 31(2).

GBGStreamingStatistics.DensityEstimation.gamma_kernel — Constant
gamma_kernel

The gamma kernel (Chen 2000) for a density on the half-line $[0,\infty)$ — a varying-shape asymmetric kernel: at the query point $x$ it is the modified (bias-reduced) $\mathrm{Gamma}(\rho(x),\,b)$ density in the data argument (Chen's $f_2$: shape $\rho(x) = x/b$ in the interior — so the kernel mean is exactly $x$, removing the $f'$ bias of the naive $x/b+1$ form — and $(x/b)^2/4 + 1$ within $2b$ of the edge), so its support matches the data and no mass leaks past 0. Passed as kernel = gamma_kernel, density returns the boundary-bias-free estimate $\hat f(x) = \tfrac1n \sum_j n_j\,\mathrm{Gamma}(c_j;\,\rho(x),\,b)$ ($O(b)$ bias uniformly, including at the boundary where a symmetric kernel is inconsistent; the variance self-adapts, tightening toward the edge). Use it for non-negative quantities such as droplet radii — an alternative to (and usually sharper than) the bounds renormalization. The bandwidth defaults to $\hat\sigma\,n^{-2/5}$ (the gamma-kernel rate; pass h to override). degree, adaptive, and bounds do not apply — the kernel is its own degree-0, boundary-free estimator.

Reference: S. X. Chen (2000), Probability density function estimation using gamma kernels, Ann. Inst. Statist. Math. 52(3).

GBGStreamingStatistics.DensityEstimation.density — Method
density(summary::Histogram1D, x; degree = 0, h = nothing, adaptive = false, kernel = gaussian_kernel, bounds = nothing)   # ≡ f_X

Estimand. the marginal (Lebesgue) density $f_X = \mathrm{d}\mu_X/\mathrm{d}\lambda$ of the conditioning variable $X$, defined by $P(X \in A) = \int_A f_X\,\mathrm{d}\lambda$.

Estimator. a binned local smoother of the counts $n_j$ at centers $c_j$, with two orthogonal knobs:

  • degree — the local-polynomial order. degree = 0 (default) is the binned KDE / WARPing $\hat f(x) = \frac1n \sum_j (n_j/h_j)\, K((x-c_j)/h_j)$ ($\int K = 1$). degree ≥ 1 is the local-log-polynomial (local-likelihood) estimator (Loader 1996): fit $\log f$ by a degree-degree polynomial through a binned local Poisson likelihood and report $\hat f(x) = e^{\hat\beta_0}$. degree = 1 (log-linear) is exact for an exponential density, so it tracks the exponential / stretched-exponential tails a flat KDE smears; degree = 2 (log-quadratic) is exact for a Gaussian. It falls back to the KDE where the local fit is degenerate or runs away in a sparse tail.
  • adaptive — the bandwidth. false (default) uses the fixed h; true uses the Abramson variable bandwidth — the kernel width scales by $(\tilde f/g)^{-1/2}$ (a pilot $\tilde f$ at h, $g$ its geometric mean), widening in the sparse tails: far less tail variance (Abramson 1982). h is the fixed bandwidth or the pilot; it defaults to the kernel- and degree-aware normal-reference rule (bandwidth, §4.5 — Silverman's $(4/3)^{1/5}\hat\sigma\,n^{-1/5}$ for the Gaussian kernel at degree 0/1, wider at the $n^{-1/9}$ rate for degree 2). (The KDE uses the sample-point $h_j$ per bin; the local-log fit uses one balloon $h(x)$ at the query.)
  • bounds — the support of the density, passed as the tuple (lower, upper) (e.g. (0.0, Inf) for a positive quantity such as a droplet radius), or nothing (default, unbounded). When given, the degree-0 KDE is renormalized by the kernel mass inside the support: $\hat f(x) \big/ \int_a^b K_h(x-u)\,\mathrm{d}u$ (Jones 1993). This corrects the boundary bias that otherwise drops the estimate to $\approx$ half the true value at the edge. (Degree $\ge 1$ is already boundary-adaptive, so bounds is a degree-0 option.)

The four corners (fixed/variable $\times$ KDE/local-log) and everything between are one call. kernel is any $K$ with $\int K = 1$ (gaussian_kernel default, epanechnikov_kernel); for bounded / positive support pass the asymmetric gamma_kernel (half-line) or beta_kernel (unit interval), which are boundary-bias-free by construction. A vector of query points returns a vector. The FFT amortization of the degree = 0, fixed-h convolution over a bandwidth grid is forthcoming (CLAUDE.md roadmap).

julia> h = Histogram1D(-1.0, 1.0, 2);

julia> observe!(h, [0.4]);          # one sample, binned at center 0.5

julia> round(density(h, 0.5; h = 0.2); digits = 4)
1.9947

References: I. S. Abramson (1982), On bandwidth variation in kernel estimates—a square root law, Ann. Statist. 10(4) (variable bandwidth); C. R. Loader (1996), Local likelihood density estimation, Ann. Statist. 24(4) (the local-log-polynomial estimator); M. C. Jones (1993), Simple boundary correction for kernel density estimation, Statist. Comput. 3(3) (the bounds renormalization).

GBGStreamingStatistics.DensityEstimation.density_standard_error — Method
density_standard_error(summary::Histogram1D, x; h = nothing, kernel = gaussian_kernel, degree = 0)   # ≡ SE[f̂(x)]

Estimand. the pointwise standard error of the density estimator density at $x$ — $\mathrm{SE}(x) = \sqrt{\operatorname{Var}\hat f_h(x)}$ with the kernel-density asymptotic variance

\[\operatorname{Var}\hat f_h(x) \approx \frac{R(K)\,f_X(x)}{n h}, \qquad R(K) = \int K^2.\]

Estimator. $\sqrt{R(K)\,\hat f_h(x)/(n h)}$ from the recovered $\hat f_h(x)$, the count $n$, the bandwidth $h$ (default the §4.5 normal reference), and $R(K)$ by quadrature. The pointwise variability band is $\hat f_h(x) \pm z\,\mathrm{SE}(x)$ ($z = 1.96$ for 95\%) — a band about $\mathbb{E}\hat f_h$, so it covers $f_X$ where the $O(h^2)$ smoothing bias is small and narrows that coverage at a sharp mode or in a tail. Degree 0/1 (the KDE variance; degree $\ge 2$ and the variable bandwidth are a coverage gap); a vector of query points returns a vector.

julia> h = Histogram1D(-6.0, 6.0, 600);

julia> observe!(h, [-0.4, 0.1, 0.2, 0.9, 1.3]);

julia> density_standard_error(h, 0.5) > 0
true

GBGStreamingStatistics.DensityEstimation.epanechnikov_kernel — Method
epanechnikov_kernel(u)

The Epanechnikov kernel $K(u) = \tfrac{3}{4}(1 - u^2)$ for $|u| \le 1$ (zero outside) — the MSE-optimal second-order kernel ($\int K = 1$, $\mu_2(K) = 1/5$, roughness $R(K) = 3/5$). Pass it as kernel = epanechnikov_kernel; its compact support touches only the bins within $h$ of the query point. bandwidth is kernel-aware, so it returns the matched Epanechnikov $h \approx 2.34\,\hat\sigma\,n^{-1/5}$ ($2.21\times$ the Gaussian $h$) automatically — no manual rescaling.

GBGStreamingStatistics.DensityEstimation.gaussian_kernel — Method
gaussian_kernel(u)

The standard Gaussian smoothing kernel $K(u) = e^{-u^2/2}/\sqrt{2\pi}$ ($\int K = 1$, $\mu_2(K) = 1$, roughness $R(K) = 1/(2\sqrt{\pi})$) — the density default.
