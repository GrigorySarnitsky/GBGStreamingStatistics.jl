DensityEstimation

The marginal density $\equiv f_X$ (§4.1): the flagship density and its pointwise variability band, the smoothing kernels it accepts, and the parametric starts for its semiparametric mode.

Density

GBGStreamingStatistics.DensityEstimation.density — Function
density(summary::Histogram1D, x; degree = 0, h = nothing, adaptive = false,
        kernel = gaussian_kernel, bounds = nothing, start = nothing,
        normalize = false, binning = :linear)   # ≡ f_X

Estimand. the marginal (Lebesgue) density $f_X = \mathrm{d}\mu_X/\mathrm{d}\lambda$ of the conditioning variable $X$, defined by $P(X \in A) = \int_A f_X\,\mathrm{d}\lambda$.

Estimator. the smoothed estimate $\hat f_h(x)$, evaluated at the query point(s) x — a scalar to get the density at one point, or a vector to get the whole curve — from the accumulated summary. It is a binned local smoother of the summary counts $n_j$ at bin centers $c_j$, shaped by these knobs:

  • degree — the local-polynomial order. degree = 0 (default) is the binned KDE / WARPing $\hat f(x) = \frac1n \sum_j (n_j/h_j)\, K((x-c_j)/h_j)$ ($\int K = 1$). degree $\ge 1$ is the local-log-polynomial (local-likelihood) estimator (Loader 1996): fit $\log f$ by a degree-degree polynomial through a binned local Poisson likelihood and report $\hat f(x) = e^{\hat\beta_0}$. degree = 1 (log-linear) is exact for an exponential density, so it tracks the exponential / stretched-exponential tails a flat KDE smears; degree = 2 (log-quadratic) is exact for a Gaussian. It falls back to the KDE where the local fit is degenerate or runs away in a sparse tail.
  • h — the smoothing bandwidth: the kernel scale, the one knob that sets the bias–variance trade-off (larger h smooths more — less variance, more bias). Pass a positive number, or leave it nothing (default) to select one from the data by the kernel- and degree-aware normal-reference rule (bandwidth, §4.5 — Silverman's $(4/3)^{1/5}\hat\sigma\,n^{-1/5}$ for the Gaussian kernel at degree 0/1, wider at the $n^{-1/9}$ rate for degree 2). For a shape-adaptive choice, compute bandwidth(summary; rule = :sj) (or :isj / :aic) yourself and pass the number. The asymmetric gamma_kernel / beta_kernel take their own scale $b$ here (rate $n^{-2/5}$) in place of the symmetric h.
  • adaptive — whether the bandwidth varies with the local density. false (default) holds h fixed everywhere; true uses the Abramson variable bandwidth — the kernel width scales by $(\tilde f/g)^{-1/2}$ (a pilot $\tilde f$ at the bandwidth h, $g$ its geometric mean), widening in the sparse tails for far less tail variance (Abramson 1982). It is orthogonal to how h is chosen, so it composes with the data-driven bandwidth — pass h = bandwidth(summary; rule = :sj) to vary a shape-adaptive global scale locally (choosing the global bandwidth and varying it by location are independent: the chosen h becomes the Abramson pilot). (Fixed-h KDE uses the sample-point $h_j$ per bin; the local-log fit uses one balloon $h(x)$ at the query.)
  • bounds — the support of the density, passed as the tuple (lower, upper) (e.g. (0.0, Inf) for a positive quantity such as a droplet radius), or nothing (default, unbounded). When given, the degree-0 KDE is renormalized by the kernel mass inside the support: $\hat f(x) \big/ \int_a^b K_h(x-u)\,\mathrm{d}u$ (Jones 1993). This corrects the boundary bias that otherwise drops the estimate to $\approx$ half the true value at the edge. (degree $\ge 1$ is already boundary-adaptive, so bounds is a degree-0 option.)
  • start — a parametric start (Hjort & Glad 1995): the semiparametric estimator $\hat f(x) = p(x;\hat\theta)\,\frac1{nh}\sum_j \frac{n_j}{p(c_j;\hat\theta)}\,K((x-c_j)/h)$, which multiplies a fitted parametric model $p(\cdot;\hat\theta)$ by a KDE of its correction (the local relative error). $\hat\theta$ is fit by method of moments from the recovered $\hat\mu$, $\hat\sigma^2$, so the start is itself a functional of the summary. The estimate is near-exact wherever the start is correct (the correction is then $\equiv 1$) and degrades only to a bias-corrected KDE where it is not — a tail-friendly bias reduction. Pass one of normal_start, lognormal_start, gamma_start, exponential_start, inverse_gaussian_start. It is a degree-0, fixed-h, symmetric-kernel estimator (degree $\ge 1$, adaptive, bounds, and the asymmetric kernels do not combine with it; use normalize for $\int\hat f = 1$).
  • normalize — when true, divide the estimate by $\int\hat f$ over the summary's range (intersected with the estimator's support), so $\int\hat f = 1$ exactly. The symmetric KDE already integrates to $\approx 1$; the asymmetric kernels and a parametric start do not, so this is their finishing step.
  • binning — where each bin's mass sits for the post-hoc evaluation. :linear (the default) places it at the recovered within-bin centroid $c_j + S_1^{(j)}/n_j$ (from the stored first power-sum $S_1$), which matches the bin's own first moment, so the binned estimate converges to the exact KDE at $O(\Delta^2)$ in the bin width $\Delta$; :simple places it at the geometric bin center $c_j$, the $O(\Delta)$ mass-at-center approximation. The centroid is read from data already in the summary, so the higher-order accuracy is free; it applies to every path (KDE, local-log, start, asymmetric kernel).

The four corners (fixed/variable $\times$ KDE/local-log) and everything between are one call. kernel is any $K$ with $\int K = 1$ (gaussian_kernel default, epanechnikov_kernel); for bounded / positive support pass the asymmetric gamma_kernel (half-line) or beta_kernel (unit interval), which are boundary-bias-free by construction — each is its own degree-0, boundary-free estimator, so degree, adaptive, and bounds do not apply to it (and a parametric start needs a symmetric kernel). A vector of query points returns a vector. The FFT amortization of the degree = 0, fixed-h convolution over a bandwidth grid is forthcoming (CLAUDE.md roadmap).

julia> h = Histogram1D(-1.0, 1.0, 2);

julia> observe!(h, [0.4]);          # one sample at 0.4

julia> round(density(h, 0.4; h = 0.2); digits = 4)   # linear binning centers the bump at 0.4 (the centroid)
1.9947

References:

  • I. S. Abramson (1982), On bandwidth variation in kernel estimates—a square root law, Ann. Statist. 10(4) (variable bandwidth).
  • C. R. Loader (1996), Local likelihood density estimation, Ann. Statist. 24(4) (the local-log-polynomial estimator).
  • M. C. Jones (1993), Simple boundary correction for kernel density estimation, Statist. Comput. 3(3) (the bounds renormalization).
  • N. L. Hjort & I. K. Glad (1995), Nonparametric density estimation with a parametric start, Ann. Statist. 23(3) (the start estimator).

GBGStreamingStatistics.DensityEstimation.density_standard_error — Function
density_standard_error(summary::Histogram1D, x; h = nothing,
                       kernel = gaussian_kernel, degree = 0)   # ≡ SE[f̂(x)]

Estimand. the pointwise standard error of the density estimator density at $x$ — $\mathrm{SE}(x) = \sqrt{\operatorname{Var}\hat f_h(x)}$ with the kernel-density asymptotic variance

\[\operatorname{Var}\hat f_h(x) \approx \frac{R(K)\,f_X(x)}{n h}, \qquad R(K) = \int K^2.\]

Estimator. $\sqrt{R(K)\,\hat f_h(x)/(n h)}$ from the recovered $\hat f_h(x)$, the count $n$, the bandwidth h (default the §4.5 normal reference), and the roughness $R(K) = \int K^2$ of the smoothing kernel $K$ — any with $\int K = 1$, default gaussian_kernel — by quadrature. The pointwise variability band is $\hat f_h(x) \pm z\,\mathrm{SE}(x)$ ($z = 1.96$ for 95\%) — a band about $\mathbb{E}\hat f_h$, so it covers $f_X$ where the $O(h^2)$ smoothing bias is small and narrows that coverage at a sharp mode or in a tail. degree 0/1 (the KDE variance; degree $\ge 2$ and the variable bandwidth are a coverage gap); a vector of query points returns a vector.

julia> h = Histogram1D(-6.0, 6.0, 600);

julia> observe!(h, [-0.4, 0.1, 0.2, 0.9, 1.3]);

julia> density_standard_error(h, 0.5) > 0
true

Asymmetric kernels

The smoothing kernel passed as density(…; kernel = …). The symmetric kernels (gaussian_kernel / epanechnikov_kernel, or any callable with $\int K = 1$) live on the Kernels page. The bounded/positive-support asymmetric kernels are AsymmetricKernel values — gamma_kernel for $[0,\infty)$, beta_kernel for $[0,1]$, or a custom one — boundary-bias-free by construction.

GBGStreamingStatistics.DensityEstimation.gamma_kernel — Constant
gamma_kernel

The gamma kernel (Chen 2000) for a density on the half-line $[0,\infty)$ — a varying-shape asymmetric kernel: at the query point $x$ it is the modified (bias-reduced) $\mathrm{Gamma}(\rho(x),\,b)$ density in the data argument (Chen's $f_2$: shape $\rho(x) = x/b$ in the interior — so the kernel mean is exactly $x$, removing the $f'$ bias of the naive $x/b+1$ form — and $(x/b)^2/4 + 1$ within $2b$ of the edge), so its support matches the data and no mass leaks past 0. Passed as kernel = gamma_kernel, density returns the boundary-bias-free estimate $\hat f(x) = \tfrac1n \sum_j n_j\,\mathrm{Gamma}(c_j;\,\rho(x),\,b)$ ($O(b)$ bias uniformly, including at the boundary where a symmetric kernel is inconsistent; the variance self-adapts, tightening toward the edge). Use it for non-negative quantities such as droplet radii — an alternative to (and usually sharper than) the bounds renormalization. The bandwidth defaults to $\hat\sigma\,n^{-2/5}$ (the gamma-kernel rate; pass h to override, or the data-driven Chen plug-in bandwidth(summary; rule = :plugin, kernel = gamma_kernel), $\approx 1.4\text{–}1.7\times$ lower ISE on skewed data). degree, adaptive, and bounds do not apply — the kernel is its own degree-0, boundary-free estimator.

Reference: S. X. Chen (2000), Probability density function estimation using gamma kernels, Ann. Inst. Statist. Math. 52(3).

GBGStreamingStatistics.DensityEstimation.beta_kernel — Constant
beta_kernel

The beta kernel (Chen 1999) for a density on the unit interval $[0,1]$ — the bounded-interval analog of gamma_kernel: at $x$ it is the modified (bias-reduced) $\mathrm{Beta}$ density in the data argument (Chen's $f_2$: interior shapes $(x/b,\,(1-x)/b)$, with a $\sqrt{\,\cdot\,}$ correction within $2b$ of an edge), boundary-bias-free at both edges. Pass kernel = beta_kernel with data scaled to $[0,1]$; the bandwidth default, the knob restrictions, and the $n^{-2/5}$ rate are as for gamma_kernel.

Reference: S. X. Chen (1999), Beta kernel estimators for density functions, Comput. Statist. Data Anal. 31(2).

GBGStreamingStatistics.DensityEstimation.AsymmetricKernel — Type
AsymmetricKernel(pdf, support)
AsymmetricKernel(pdf, support, weight)

A varying-shape asymmetric kernel for density on a bounded or half-line support — the boundary-bias-free analog of a symmetric smoothing kernel (Chen 1999, 2000). The built-ins are gamma_kernel for $[0,\infty)$ and beta_kernel for $[0,1]$; construct one directly to plug in a custom boundary kernel. The three fields are the construction contract:

  • pdf(c, x, b) — the kernel as a density in the data argument $c$, whose shape is set by the evaluation point $x$ and bandwidth $b$ (normalized: $\int \texttt{pdf}(c, x, b)\,\mathrm{d}c = 1$ over the support, for each $x$ and $b$). The estimate is the binned reduction $\hat f(x) = \tfrac1n \sum_j n_j\,\texttt{pdf}(c_j, x, b)$ over the bin counts $n_j$ at centers $c_j$ — post hoc and mergeable.
  • support — the data domain the kernel covers, as a (lower, upper) tuple (e.g. (0.0, Inf)).
  • weight(x) — the AMISE local-scale weight $w(x)$: the leading bias is $\tfrac12 b\,w(x)\,f''(x)$ and the variance $\propto w(x)^{-1/2}$ ($w(x) = x$ for the gamma kernel, $x(1-x)$ for the beta). It is used only by bandwidth(…; rule = :plugin). The two-argument constructor leaves it unset (nothing): rule = :plugin then errors rather than silently use a wrong weight, while the $\hat\sigma\,n^{-2/5}$ rule of thumb (rule = :normal) needs no weight and still applies.
using SpecialFunctions: loggamma
# the built-in gamma kernel, as a template (Chen's modified f₂ shape):
mygamma = AsymmetricKernel(
    (c, x, b) -> c > 0 ? (ρ = x < 2b ? (x / b)^2 / 4 + 1 : x / b;
                          exp((ρ - 1) * log(c) - c / b - ρ * log(b) - loggamma(ρ))) : 0.0,
    (0.0, Inf),
    x -> x)                       # the AMISE weight w(x) = x, for rule = :plugin
density(summary, 1.0; kernel = mygamma)

References:

  • S. X. Chen (1999), Beta kernel estimators for density functions, Comput. Statist. Data Anal. 31(2).
  • S. X. Chen (2000), Probability density function estimation using gamma kernels, Ann. Inst. Statist. Math. 52(3).

Parametric starts

The moment-fitted parametric models for the Hjort–Glad semiparametric estimator density(…; start = …), which multiplies the start by a KDE of its correction. The built-ins are normal_start, lognormal_start, gamma_start, exponential_start, and inverse_gaussian_start; a custom model is a ParametricStart — supply the moment fit, the log-density, and the support.

GBGStreamingStatistics.DensityEstimation.normal_start — Constant
normal_start

A Gaussian (normal) parametric start on $(-\infty,\infty)$: $p(x;\hat\mu,\hat\sigma^2)$ with $\hat\mu$, $\hat\sigma^2$ the recovered sample mean and variance. Pass start = normal_start to density; the estimate is then near-exact on genuinely Gaussian data and reduces to a bias-corrected KDE otherwise.

source
GBGStreamingStatistics.DensityEstimation.lognormal_start — Constant
lognormal_start

A log-normal parametric start on $(0,\infty)$, parameters by method of moments ($s^2 = \log(1+\hat\sigma^2/\hat\mu^2)$, $m = \log\hat\mu - s^2/2$). A natural start for a positively skewed quantity such as a droplet radius; pass start = lognormal_start.

source
GBGStreamingStatistics.DensityEstimation.gamma_start — Constant
gamma_start

A gamma parametric start on $(0,\infty)$, shape $k = \hat\mu^2/\hat\sigma^2$ and scale $\theta = \hat\sigma^2/\hat\mu$ by method of moments. For a non-negative quantity; pass start = gamma_start.

source
GBGStreamingStatistics.DensityEstimation.exponential_start — Constant
exponential_start

An exponential parametric start on $[0,\infty)$, rate $\hat\lambda = 1/\hat\mu$ (a one-parameter start fit from the mean alone). Pass start = exponential_start; pairs with the degree = 1 log-linear fit as the two exponential-tail tools.

source
GBGStreamingStatistics.DensityEstimation.inverse_gaussian_start — Constant
inverse_gaussian_start

An inverse-Gaussian parametric start on $(0,\infty)$, mean $\hat\mu$ and shape $\hat\lambda = \hat\mu^3/\hat\sigma^2$ by method of moments — a positive start with an exponentially decaying right tail (lighter than the log-normal's). Pass start = inverse_gaussian_start.

GBGStreamingStatistics.DensityEstimation.ParametricStart — Type
ParametricStart(fit, logpdf, support)

A parametric start for the Hjort–Glad semiparametric density (Hjort & Glad 1995). Passed as density(…; start = …), it multiplies the moment-fitted model $p(\cdot;\hat\theta)$ by a kernel estimate of the correction $f_X/p$ — near-exact where the model fits (the bias is driven by $(f_X/p)''$, not $f_X''$), degrading only to a kernel-of-the-ratio bias where it does not. The built-ins are normal_start, lognormal_start, gamma_start, exponential_start, and inverse_gaussian_start; construct one directly to plug in a custom parametric model. The three fields are the construction contract:

  • fit(mean, variance) — fit the model parameters from the recovered moments by method of moments, returning a parameter tuple. Fitting from the mean and variance (not the raw data) is what keeps the whole estimate mergeable: $\hat\theta$ is itself a post-hoc functional of the summary.
  • logpdf(x, params) — the model log-density $\log p(x;\hat\theta)$, returning $-\infty$ off the support. density reweights each bin by $1/p(c_j;\hat\theta)$ through this log form (stable in the tails, where $p$ is tiny).
  • support — the domain the model is positive on, as a (lower, upper) tuple (e.g. (0.0, Inf)).
julia> rayleigh = ParametricStart(
           (mean, variance) -> (mean * sqrt(2 / π),),                            # σ from the mean
           (x, p) -> x > 0 ? log(x) - 2 * log(p[1]) - x^2 / (2 * p[1]^2) : -Inf,  # Rayleigh log-density
           (0.0, Inf));

julia> rayleigh isa ParametricStart
true

Reference: N. L. Hjort & I. K. Glad (1995), Nonparametric density estimation with a parametric start, Ann. Statist. 23(3).
