DensityEstimation

The marginal density density $\equiv f_X$ (§4.1).

GBGStreamingStatistics.DensityEstimation.density — Method
density(summary::Histogram1D, x; degree = 0, h = nothing, adaptive = false, kernel = gaussian_kernel)   # ≡ f_X

Estimand. the marginal (Lebesgue) density $f_X = \mathrm{d}\mu_X/\mathrm{d}\lambda$ of the conditioning variable $X$, defined by $P(X \in A) = \int_A f_X\,\mathrm{d}\lambda$.

Estimator. a binned local smoother of the counts $n_j$ at centers $c_j$, with two orthogonal knobs:

  • degree — the local-polynomial order. degree = 0 (default) is the binned KDE / WARPing $\hat f(x) = \frac1n \sum_j (n_j/h_j)\, K((x-c_j)/h_j)$ ($\int K = 1$). degree ≥ 1 is the local-log-polynomial (local-likelihood) estimator (Loader 1996): fit $\log f$ by a degree-degree polynomial through a binned local Poisson likelihood and report $\hat f(x) = e^{\hat\beta_0}$. degree = 1 (log-linear) is exact for an exponential density, so it tracks the exponential / stretched-exponential tails a flat KDE smears; degree = 2 (log-quadratic) is exact for a Gaussian. It falls back to the KDE where the local fit is degenerate or runs away in a sparse tail.
  • adaptive — the bandwidth. false (default) uses the fixed h; true uses the Abramson variable bandwidth — the kernel width scales by $(\tilde f/g)^{-1/2}$ (a pilot $\tilde f$ at h, $g$ its geometric mean), widening in the sparse tails: far less tail variance (Abramson 1982). h is the fixed bandwidth or the pilot; it defaults to the kernel- and degree-aware normal-reference rule (bandwidth, §4.5 — Silverman's $(4/3)^{1/5}\hat\sigma\,n^{-1/5}$ for the Gaussian kernel at degree 0/1, wider at the $n^{-1/9}$ rate for degree 2). (The KDE uses the sample-point $h_j$ per bin; the local-log fit uses one balloon $h(x)$ at the query.)

The four corners (fixed/variable $\times$ KDE/local-log) and everything between are one call. kernel is any $K$ with $\int K = 1$ (gaussian_kernel default, epanechnikov_kernel); a vector of query points returns a vector. The FFT amortization of the degree = 0, fixed-h convolution over a bandwidth grid is forthcoming (CLAUDE.md roadmap).

julia> h = Histogram1D(-1.0, 1.0, 2);

julia> observe!(h, [0.4]);          # one sample, binned at center 0.5

julia> round(density(h, 0.5; h = 0.2); digits = 4)
1.9947

References: I. S. Abramson (1982), On bandwidth variation in kernel estimates—a square root law, Ann. Statist. 10(4) (variable bandwidth); C. R. Loader (1996), Local likelihood density estimation, Ann. Statist. 24(4) (the local-log-polynomial estimator).

GBGStreamingStatistics.DensityEstimation.epanechnikov_kernel — Method
epanechnikov_kernel(u)

The Epanechnikov kernel $K(u) = \tfrac{3}{4}(1 - u^2)$ for $|u| \le 1$ (zero outside) — the MSE-optimal second-order kernel ($\int K = 1$, $\mu_2(K) = 1/5$, roughness $R(K) = 3/5$). Pass it as kernel = epanechnikov_kernel; its compact support touches only the bins within $h$ of the query point. bandwidth is kernel-aware, so it returns the matched Epanechnikov $h \approx 2.34\,\hat\sigma\,n^{-1/5}$ ($2.21\times$ the Gaussian $h$) automatically — no manual rescaling.

GBGStreamingStatistics.DensityEstimation.gaussian_kernel — Method
gaussian_kernel(u)

The standard Gaussian smoothing kernel $K(u) = e^{-u^2/2}/\sqrt{2\pi}$ ($\int K = 1$, $\mu_2(K) = 1$, roughness $R(K) = 1/(2\sqrt{\pi})$) — the density default.
