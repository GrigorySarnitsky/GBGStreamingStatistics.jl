DensityEstimation

The marginal density density $\equiv f_X$ (§4.1).

GBGStreamingStatistics.DensityEstimation.adaptive_density — Method
adaptive_density(summary::Histogram1D, x; h0 = nothing, kernel = gaussian_kernel)   # ≡ f_X

Estimand. the marginal density $f_X$ — the same population quantity as density.

Estimator (Abramson variable-bandwidth / sample-point KDE). A fixed-bandwidth pilot $\tilde f$ at $h_0$ sets a per-bin bandwidth $h_j = h_0\,(\tilde f(c_j)/g)^{-1/2}$ ($g$ the geometric mean of $\tilde f$ over the sample), then

\[\hat f(x) = \frac1n \sum_j \frac{n_j}{h_j}\, K\!\left(\frac{x - c_j}{h_j}\right).\]

The kernel widens where the data is sparse (a small pilot $\tilde f(c_j)$ gives a large $h_j$) and narrows in the peak, so the tails carry far less variance than a fixed bandwidth — the regime that matters for heavy / intermittent distributions. Abramson's square-root law lowers the bias to $O(h^4)$ (from the $O(h^2)$ of density). The pilot $h_0$ defaults to the global Silverman rule; kernel is any $K$ with $\int K = 1$.

Reference: I. S. Abramson (1982), On bandwidth variation in kernel estimates—a square root law, Ann. Statist. 10(4).

GBGStreamingStatistics.DensityEstimation.density — Method
density(summary::Histogram1D, x; h, kernel = gaussian_kernel)   # ≡ f_X

Estimand. the marginal (Lebesgue) density $f_X = \mathrm{d}\mu_X/\mathrm{d}\lambda$ of the conditioning variable $X$, defined by $P(X \in A) = \int_A f_X\,\mathrm{d}\lambda$.

Estimator (binned KDE / WARPing). From the bin counts $n_j$ at centers $c_j$ of summary (a Histogram1D), the total count $n$, and a kernel $K$ with $\int K = 1$ and bandwidth $h$,

\[\hat f_h(x) = \frac{1}{n\,h} \sum_{j} n_j\, K\!\left(\frac{x - c_j}{h}\right),\]

the binned approximation to $\frac{1}{nh}\sum_i K\!\left(\frac{x - X_i}{h}\right)$ (Hall & Wand 1996). The bandwidth $h$ comes from bandwidth (or is supplied directly); kernel defaults to gaussian_kernel — pass epanechnikov_kernel, or any $K$ with $\int K = 1$. Here the convolution is a direct sum over occupied bins; the FFT amortization of the sum over a whole bandwidth grid is forthcoming (CLAUDE.md roadmap). A vector of query points returns a vector of densities.

julia> h = Histogram1D(-1.0, 1.0, 2);

julia> observe!(h, [0.4]);          # one sample, binned at center 0.5

julia> round(density(h, 0.5; h = 0.2); digits = 4)
1.9947

GBGStreamingStatistics.DensityEstimation.epanechnikov_kernel — Method
epanechnikov_kernel(u)

The Epanechnikov kernel $K(u) = \tfrac{3}{4}(1 - u^2)$ for $|u| \le 1$ (zero outside) — the MSE-optimal second-order kernel ($\int K = 1$, $\mu_2(K) = 1/5$, roughness $R(K) = 3/5$). Pass it as kernel = epanechnikov_kernel; its compact support touches only the bins within $h$ of the query point. Note bandwidth returns a Gaussian-tuned $h$ — the AMISE-optimal Epanechnikov bandwidth is $\approx 2.21\times$ larger, so scale it (or supply $h$ directly).

GBGStreamingStatistics.DensityEstimation.gaussian_kernel — Method
gaussian_kernel(u)

The standard Gaussian smoothing kernel $K(u) = e^{-u^2/2}/\sqrt{2\pi}$ ($\int K = 1$, $\mu_2(K) = 1$, roughness $R(K) = 1/(2\sqrt{\pi})$) — the density default.
