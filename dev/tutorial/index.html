Getting started

This tour shows the intended samples in, statistics out workflow. The architectural spine is

empirical measure → mergeable summary → post-hoc-smoothed estimator,

and the API follows it directly.

Status

Everything in this tour is implemented and runnable today, single-node on CPU or GPU. The Kramers–Moyal / SDE-reading functionals (drift and diffusion), the higher Kramers–Moyal coefficients, and the Pawula / Markov diagnostics are not currently provided but are planned; see the Architecture for the design and roadmap.

The workflow

1. Allocate a summary. A Histogram1D is a finely binned empirical measure of a scalar variate $X$ — the summary every estimator reads. It is fixed-size and lives for the whole run.

using GBGStreamingStatistics

# a fixed range and bin count: the summary never grows with the stream
summary = Histogram1D(-5.0, 5.0, 1000)

2. Observe the stream. Each batch is folded in once with observe! and discarded — the samples are never stored. Accumulation is estimand-agnostic: it commits to no estimand, bandwidth, or kernel.

# the consumer produces the batches; the package never holds the stream
for batch in stream
    observe!(summary, batch)
end

Summaries from independent chunks or devices combine with merge! — the monoid operation that makes parallel accumulation free:

merge!(summary, other_summary)

3. Estimate, post hoc. Every reported quantity is a smoothing functional of the one stored summary — computed after accumulation, at any bandwidth, for any estimand, with no second pass:

bw = bandwidth(summary)              # a global plug-in bandwidth from the recovered σ̂
fX = density(summary, 0.0; h = bw)   # the marginal density f_X at x = 0

4. Form the two-time statistics. For conditional and transition densities, the consumer (the calling code) forms lag-labelled pairs $\bigl(X(t), Y(t+\tau)\bigr)$ and bins them with observe_pairs! into a Histogram2D; the snapshot buffer and the lags to form are its business. The same post-hoc rule applies — every estimand is read off the one joint summary:

# lag labels the summary with the pair lag τ (a record, not a bandwidth)
joint = Histogram2D(-5.0, 5.0, 300, -5.0, 5.0, 300; lag = 1)
for (x_past, y_now) in pairs    # the consumer forms the lagged pairs at lag τ
    observe_pairs!(joint, x_past, y_now)
end

m  = conditional_mean(joint, 0.0; h = 0.3)                     # E[Y | X = 0]
s2 = conditional_variance(joint, 0.0; h = 0.3)                 # Var[Y | X = 0]
# hx and hy are the bandwidths in x and y
pτ = transition_density(joint, 0.0, 0.0; hx = 0.3, hy = 0.2)   # p_τ(0 | 0)
