Getting started

This tour shows the intended samples in, statistics out workflow. The architectural spine is

empirical measure → mergeable summary → post-hoc-smoothed estimator,

and the API follows it directly.

Status

Everything in this tour is implemented and runnable today, single-node on CPU or GPU. See the Architecture for the design and the roadmap of what is still forthcoming (the Pawula / Markov diagnostics and the higher Kramers–Moyal coefficients).

The workflow

1. Allocate a summary. A Histogram1D is a finely binned empirical measure of a conditioning variable $X$ — the canonical summary. It is fixed-size and lives for the whole run.

using GBGStreamingStatistics

summary = Histogram1D(-5.0, 5.0, 1000)   # fixed range and bin count; never grows with the stream

2. Observe the stream. Each batch is folded in once with observe! and then discarded — the samples are never stored. Accumulation is estimand-agnostic: it commits to no channel, bandwidth, or kernel.

for batch in stream          # the consumer produces the batches; the package never holds the stream
    observe!(summary, batch)
end

Summaries from independent chunks or devices combine with merge! — the mergeable-monoid operation that makes multi-threaded and multi-device accumulation free:

merge!(summary, other_summary)

3. Estimate, post hoc. Every reported quantity is a smoothing functional of the one stored summary — computed after accumulation, at any bandwidth, for any channel, with no second pass:

bw = bandwidth(summary)              # a global plug-in bandwidth from the recovered σ̂
fX = density(summary, 0.0; h = bw)   # the marginal density f_X at x = 0

4. Two-time statistics. For conditional and transition densities and the conditional increment moments, the consumer forms lag-labelled pairs $\bigl(X(t), Y(t+\tau)\bigr)$ and bins them with observe_pairs! into a Histogram2D; the snapshot buffer and lag policy stay consumer-side. The same post-hoc rule applies — every estimand is read off the one joint summary:

joint = Histogram2D(-5.0, 5.0, 300, -5.0, 5.0, 300; lag = 1)
for (x_past, y_now) in pairs    # the consumer forms the lagged pairs at lag τ
    observe_pairs!(joint, x_past, y_now)
end

m  = conditional_mean(joint, 0.0; h = 0.3)                     # E[Y | X = 0]
D1 = drift(joint, 0.0; h = 0.3)                                # Kramers–Moyal drift D⁽¹⁾(0)
pτ = transition_density(joint, 0.0, 0.0; hx = 0.3, hy = 0.2)   # transition density p_τ(0 | 0)
