GBGStreamingStatistics.jl

GBGStreamingStatistics.jl is a backend-agnostic library for online nonparametric statistics. It estimates marginal densities, conditional expectations, conditional and two-time transition densities, and standard functionals of these (Kramers–Moyal coefficients, drift and diffusion, the Pawula diagnostic), from a stream of samples that is never stored — each sample is observed once, folded into a fixed-size summary, and discarded.

The summary (a fine histogram with per-bin moments) is accumulated online and is estimand-agnostic: every reported quantity is a post-hoc smoothing functional of that one summary, so there is no storage of the underlying state and no recompute-from-raw reruns. It is a mergeable monoid — in fact a cone (combine across threads, devices, or time-chunks by addition, or weight and superpose for hyperstatistics) — and targets both CPU and GPU array backends on a single shared-memory node. The library is domain-neutral and model-neutral — it assumes no statistical model (no stationarity, Markov, diffusion, or parametric premise): it consumes a stream of values (optionally lagged pairs) and returns estimators.

When it fits. It is built for settings where the data is a stream and storing or re-reading it is the bottleneck:

  • inside a time-marching solver — fold each step's samples into the summary and discard, with no trajectory storage and no second pass;
  • one pass, many views — every bandwidth, channel, and conditioning value is computed post hoc from the one summary, so exploring them never re-reads the raw stream;
  • parallel and chunked — mergeable summaries combine across threads, GPUs, and time windows;
  • memory-tight or GPU-resident — the summary is fixed-size and the accumulation hot path is allocation-free and runs on the GPU.

It is used, for example, in turbulence (conditional and Lagrangian statistics, transition densities, drift and diffusion) and molecular dynamics (the van Hove and intermediate scattering functions are two-time conditional densities) — but nothing in the library is specific to a domain.

Status

The summaries Histogram1D and Histogram2D (power-sums about the bin center, observe! / observe_pairs! / merge! / scale! / bin_index, with a Float-count cone variant for hyperstatistics / forgetting), the marginal density (§4.1), global bandwidth selection, and the conditional mean and variance (conditional_mean, conditional_variance, §4.2), the conditional and transition densities (conditional_density, transition_density, §4.3), and the Kramers–Moyal drift / diffusion (§4.4) are implemented and tested on CPU and GPU (Gaussian, bivariate-Gaussian, and Ornstein–Uhlenbeck oracles, mergeability, allocation, AMD-ROCm parity). The response-aware local bandwidth and the higher Kramers–Moyal / Pawula / Markov diagnostics are forthcoming; see the Architecture for the design and roadmap.

Installation

This is an unregistered package, so it is not listed in the General Julia registry. To install it, run:

]add https://github.com/GrigorySarnitsky/GBGStreamingStatistics.jl

or

using Pkg

Pkg.add(url="https://github.com/GrigorySarnitsky/GBGStreamingStatistics.jl")

Then you can use it as usual:

using GBGStreamingStatistics

Main components

The package splits into a universal lower half (the summaries and how they accumulate, shared verbatim by every consumer) and an estimator upper half (the estimands):

  • Accumulators: the foundation — AbstractAccumulator, the interface of every mergeable online summary of the empirical measure $\hat\mu_n = \frac1n\sum_i \delta_{X_i}$ (you observe! samples into it and merge! two together). The concrete summaries live in Histograms.
  • Histograms: the summaries — Histogram1D and Histogram2D, both <: AbstractAccumulator. Each is a finely binned empirical measure — the fine-grained measure that post-hoc smoothing later coarse-grains — holding per-bin counts and power-sums about the bin center; accumulation runs on CPU or GPU, and summaries combine with merge!. With bin_index and observe_pairs! for two-time statistics.
  • DensityEstimation: the marginal density density $\equiv f_X$ — one call over the binned KDE, the local-log-polynomial (degree), and the Abramson variable bandwidth (adaptive, for tails), the asymmetric gamma_kernel / beta_kernel for bounded/positive support, the parametric start (a moment-fitted model corrected by a KDE; Hjort & Glad 1995), and exact normalize — plus density_standard_error, the pointwise variability band.
  • Regression: the conditional mean conditional_mean $\equiv m(x)$ and variance conditional_variance $\equiv \sigma^2(x)$ (local-linear).
  • ConditionalDensity: the conditional density conditional_density $\equiv f_{Y\mid X}$ and two-time transition density transition_density $\equiv p_\tau(y\mid x)$ (double-kernel).
  • MarkovInference: conditional increment moments and their functionals — increment_moment $\equiv M_n(x,\tau)$, kramers_moyal $\equiv D^{(n)}$, drift $\equiv D^{(1)}$, and diffusion $\equiv D^{(2)}$ (with the pawula_quotient and markov_test diagnostics forthcoming).
  • Bandwidth: bandwidth selection — the kernel- and degree-aware normal-reference rule (Silverman the Gaussian/degree-0 case), the data-driven Sheather–Jones (rule = :sj, :isj), fit-based AIC (rule = :aic), and asymmetric-kernel Chen plug-in (rule = :plugin) selectors, with the response-aware local plug-in $h^\star(x)$ forthcoming.
